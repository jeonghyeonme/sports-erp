**한 일**
- **D73 결정**: 화면 안 순서 = 처리할 일 → 지금 상태 → 입력 폼 → 쌓이는 기록. 쌓이는 목록 아래 폼은 머리글 버튼 + 모달. 대안(화면 안 탭, 처리 대기함 링크 위치 이동)과 비교는 D73.
- **근태관리**(`pages/AttendancePage.tsx`): 지점 관리자의 휴가 승인함을 맨 위로. 대기가 없으면 그리지 않는다 — 처음엔 늘 그렸는데 화면 캡처에서 빈 승인함이 첫 화면을 크게 차지해 바꿨다(처리 대기함이 건수를 보인다). 오늘의 근태·휴가 일수 카드 다음에 업무일지·휴가 신청 폼을 카드 두 장으로 나란히, 그 아래 내 업무일지(새 제목 + 빈 상태 문구)·내 휴가 신청 내역·이번 달 근태 기록, 맨 아래 지점 근태 요약·결근 확정(결근 확정은 여전히 휴가 승인 뒤 순서).
- **예약 관리**(`pages/ReservationsPage.tsx`): `SlotManager`를 `SlotCreateModal`(머리글 "+ 회차 등록" — 지점 관리자, `program` CREATE일 때만)과 `SlotList`("회차 목록" 절, 프로그램별 회차·예약 인원)로 나눴다. 전에는 권한이 꺼져도 폼이 보였고 서버가 403을 냈다 — 이제 버튼을 숨긴다(D60).
- 화면 도움말(근태관리·예약)과 디자인시스템 §3에 순서 규칙.
- 화면 자동 테스트 "내일 회차를 등록하면 주간 시간표에 보인다"를 모달로 고쳤다. 같이 찾은 것: 오늘이 일요일(KST)이면 내일 회차가 다음 주라 시간표(이번 주 월~일)에 없어 **일요일마다 실패하던 테스트**였다(이번 변경과 무관 — 2026-11-08 일요일에 드러남). 내일이 월요일이면 "다음 주 →"를 누르게 고쳤다.
