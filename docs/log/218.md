> [진행 로그 인덱스](README.md)

**계기**: 11주차 덱의 분량을 두고 덱에 넣을 작업·더 할 작업을 물은 데 대해, 사용자가 10주차 다음 할 일의 마지막 갈래(D67 3-③ 회원 앱 형태 재검토)를 먼저 하자고 했고 결론을 직접 냈다 — "지금 형태로 유지. 유지보수가 너무 들고, 네이티브로 개발해도 지금으로선 구색만 갖추는 것이고, 지금으로도 충분히 기능한다." 같은 대화에서 "15페이지의 API 자동 테스트·운영 반영은 중요한 내용이 아니다".
