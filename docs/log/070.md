# 070. 지점당 등록 회원 가정을 550명에서 약 280명으로 — 하루 이용자 100명과 맞췄다 (2026-10-06)

> [진행 로그 인덱스](README.md)

**계기**: 사용자가 회원관리 문서의 "3년 후 전사 ≈6만 명" 추정이 과하다고 봤다.

**원인**: design-constants의 ② 등록 회원 550명(상주인구 2,200 × 등록률 25%)과 ③ 하루 이용자 100명(D40)이 서로 맞지 않았다. 둘을 합치면 회원 한 명이 주 1.3회 온다는 뜻이 된다. ③을 200명으로 잡았을 때는 주 2.5회였다.

**바꾼 것**: ②를 ③에서 역산하도록 바꿨다(사용자 승인).
- 계산: 100명 × 7일 ÷ 주 2.5회 = **약 280명**(상주인구의 약 13%)
- 전사 회원 수: 지금 83곳 ≈2.3만 명, 3년 후 110곳 ≈3.1만 명
- 고친 문서: 회원관리(§3 산정, 트래픽 이슈), 인사정보관리(비교 기준), traffic-infra-review
- 요구사항 정의서를 다시 생성했다.
- 하루 요청 수(⑬)와 피크(⑪)는 ③ 기준이라 바뀌지 않는다. 덱도 바뀌지 않는다.

**다음**: 사용자가 "계산식들 다 검토해서 현실적인 값으로 수정할 준비"를 요청했다. design-constants 전체 체인을 검토해 수정안을 낸다(승인 후 반영).
