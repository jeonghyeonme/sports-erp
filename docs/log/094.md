# 094. 회원 웹 PWA·앱 셸 — 설치, 오프라인, 탭 아이콘·뒤로 가기·전환·당겨서 새로고침 (2026-10-10)

> [진행 로그 인덱스](README.md)

**계기**: 사용자가 회원 웹이 "너무 웹 느낌"이라며 PWA(간단한 앱 설치)를 원했다. QR 설치 안내는 이번에 빼기로 했다.

**사용자 결정(2026-10-10)** → [D45](../decisions/D45.md)
1. 아이콘: 운동 심볼(덤벨). 로고 이미지는 없다.
2. 오프라인: 앱 화면은 뜨고 "연결 없음"을 안내한다. 데이터(API)는 캐시하지 않는다.
3. 범위: 앱 셸 전체 다듬기(화면 구성·기능은 그대로).

**한 일**
- **PWA**
  - `public/assets/manifest.webmanifest`(standalone, 시작·범위 `/m/`), `public/assets/icons/*`(SVG에서 Playwright로 PNG 생성).
  - `public/sw.js`: 화면 파일만 캐시하고 `/api` 요청은 건드리지 않는다.
  - `index.html` 메타(manifest·apple-touch-icon·standalone), 프로덕션에서만 service worker 등록(`lib/pwa.ts`).
  - Worker `run_worker_first`에 `!/m/sw.js`. 그 밖의 `/m/` 바로 아래 공개 파일은 여전히 두지 않는다(member-web CLAUDE.md 갱신).
- **설치 안내**: 홈의 "앱으로 설치하기" 카드. 안드로이드는 설치 버튼, 아이폰은 "공유 → 홈 화면에 추가" 하단 시트. 앱으로 열었거나 닫으면 숨긴다(닫음은 이 기기에만 저장).
- **앱 셸**
  - 하단 탭에 아이콘을 넣고, 활성 탭은 알약 배경으로 표시한다.
  - 하위 화면(회차 선택·결제·공지)은 앱 바에 뒤로 가기와 제목을 두고, 페이지 안의 "← 목록" 링크는 없앴다.
  - 화면 전환은 떠오르는 애니메이션을 쓴다. 당겨서 새로고침을 넣었다(홈 60초 캐시도 비운다).
  - 누르면 살짝 줄어드는 피드백을 주고, 탭할 때 파란 번쩍임을 없앴다. 셸에서 글자 선택·길게 누르기 메뉴를 막았다.
  - 노치·홈 바 여백을 두고, 반투명 블러 앱 바·탭 바를 썼다.
  - 큰 제목 24px, 카드 모서리 14px. 하단 시트는 손잡이와 슬라이드 업을 붙였다.
  - 불러오는 중에는 스켈레톤을 보이고, 시작할 때 스플래시(아이콘)를 보인다. 움직임 줄이기 설정이면 애니메이션을 끈다.
  - 로그아웃은 상단 바에서 내 정보 맨 아래로 옮겼다.
- **오프라인**
  - 화면 상단에 연결 없음 띠를 보인다(로그인 화면 포함).
  - **함께 고친 버그**: 오프라인으로 앱을 열면 세션 복원이 네트워크 오류로 실패해 저장된 로그인이 지워졌다. 홈 화면 앱에서는 흔한 상황이다. 이제 토큰은 그대로 두고 "연결 없음" 화면을 보이며, 다시 연결되면 자동으로 재시도한다.

**검증**
- 커밋 hook에서 세 앱 lint·빌드와 api jest를 돌렸다.
- 프로덕션 빌드를 `vite preview`(`/m/`) + 로컬 api에 붙여 Playwright로 iPhone 13을 에뮬레이션해 확인한 것:
  - service worker 활성(범위 `/m/`), manifest(standalone·아이콘 3)
  - 설치 카드와 아이폰 안내 시트
  - 하위 화면 앱 바(뒤로 가기 → `/m/programs`)
  - 페이지를 제어한 뒤 오프라인 새로고침 → "연결 없음" 화면 → 온라인 복귀 → 자동 복원(탭 바 표시)
  - 로그아웃 위치(내 정보에 1, 상단 바에 0)
- **검증되지 않음**
  - 실제 기기 설치(안드로이드 `beforeinstallprompt`는 헤드리스에서 오지 않는다, 아이폰 홈 화면 추가)
  - 당겨서 새로고침 손동작
  - Worker 경유 `/m/sw.js` 예외(`wrangler dev` 미실행)
  - 다크 모드는 없다.

**배포**: 화면·Worker 설정 변경이라 사용자가 `npm run build:web` → `cd cloudflare-worker && npx wrangler deploy`로 올려야 한다. api 변경은 없다.
