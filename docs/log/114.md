# 114. RFP 작은 작업 6건 — 본사 근태 현황, 교육자료 탭, 회원용 강사 소개, 혼잡도 30분 경고, 오류 데이터 진단 절차, 메모리 경보 절차 (2026-10-14)

> [진행 로그 인덱스](README.md)

**계기**: log/113 재대조로 나온 누락 중 작은 것부터 처리하기로 했다(사용자, D51 우선순위).

**한 일**:
1. **본사 근태 현황**(RFP 개념도 본사→현장 근태관리): admin-web `/attendance`가 역할로 갈린다(`AttendanceEntry`). 본사는 `HqAttendancePage` — 지점(지역·이름순)·월을 골라 직원별 정상·지각·결근·조퇴·휴가와 확정 전 결근 후보 수를 본다. 조회 전용이고 이름은 직원 상세로 연결. 본사 메뉴 "인사·권한 › 근태 현황". 근태관리 A-7은 원래 "본사는 전 지점 조회만"이라 원칙 변경은 없었다 — log/113에서 "원칙이 RFP와 다르다"고 적은 것은 화면이 없던 것을 원칙으로 잘못 읽은 것이라 요약 카드를 바로잡았다. API 변경 없음(summary·absence-preview는 이미 본사 허용). `useApiList`에 `enabled` 인자를 더해 지점 목록이 오기 전에는 부르지 않는다.
2. **게시판 직원 교육자료 탭**(RFP 게시판 "본사→현장 직원관리 탭"): `GET /posts?category=`(모르는 값은 빈 목록 — scope와 같은 규칙), 게시판에 "직원 교육자료" 탭(본사 공지 + 분류 교육자료, 회원에겐 안 보임). 도움말 문구.
3. **회원용 강사 소개**(RFP "종목별 강사 정보 게시"): 프로그램 응답에 `instructorSpecialty`·`instructorBio`를 싣고(연락처는 안 실음) 회원 웹 회차 화면에 "강사 ○○ · 전문 종목 · 소개" 패널. 회원 웹이 강사 목록을 따로 부르지 않아 방문당 호출 수(⑩)는 그대로다.
4. **혼잡도 30분 경과 경고**(RFP "최대 30분 이내 반영"): 관리자 시설 카드에 "30분 넘게 갱신되지 않았습니다 — 현재 인원을 다시 입력"(운영 중 시설만), 회원 웹 홈 혼잡도 카드에 "일부 시설은 30분 넘게 갱신되지 않아 지금과 다를 수 있습니다".
5. **오류 데이터 진단 절차**(RFP 데이터관리방안): data-integrity §7 — 상태 어긋남 점검 SQL 9개(직원 캐시 지점, 퇴사자 계정·파견·담당, 종료 지점 파견, 탈퇴 회원 계정, 회차 정원 초과, 예약·결제 상태, 혼잡도 30분)와 점검별 개선 방법·절차.
6. **메모리 85% 경보 절차**(RFP 시스템 가용성): aws-lambda/README §6 — REPORT 줄 지표 필터(`MaxMemoryUsedMB`) → 평균 > 870MB 경보. 콘솔 적용은 사용자.

**근거**: D51, 근태관리 A-7, ADR-BRD-02(목록 필터 규칙), design-constants ⑩, ADR-FAC-01, data-integrity §1~5.

**검증**:
- api: `post-rules`에 분류 필터 테스트(교육자료만 1건·대조군 2건·모르는 값 빈 목록), `catalog-flow`에 회원 프로그램 목록의 강사 이름·전문 종목 테스트 — 통과. 커밋 hook이 전체 jest를 돈다.
- admin-web·member-web lint·빌드 통과.
- 진단 SQL: 로컬 PG16 시드에서 D1~D8 = 0, 한 트랜잭션에서 직원 1명 RESIGNED·회원 1명 WITHDRAWN으로 바꾸면 D2·D3·D5·D6이 1(ROLLBACK).
- 로컬 Playwright: 본사 메뉴에 "근태 현황", 경로 `홈 인사·권한 근태 현황`, 지점 요약 3행. 지점 관리자 게시판 "직원 교육자료" 탭이 `scope=HQ_TO_BRANCH&category=TRAINING_MATERIAL`로 불러 매뉴얼 1건만. 지점 관리자 시설 화면 경고 2건, 직원은 근태 화면 그대로(체크인 있음). 회원 웹 홈 경고 1건, 아침 요가 회차 화면에 "강사 박서연 · 전문 종목: 요가·필라테스". 화면 동작은 자동 테스트가 없어 **수동 확인만**.
- 메모리 경보 지표 필터는 **검증되지 않음**(AWS 콘솔).
