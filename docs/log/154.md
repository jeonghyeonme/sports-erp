# 154. 게시글 작성·수정 화면과 서식 편집기 — 허용 목록 정화 두 겹 (2026-10-22)

> [진행 로그 인덱스](README.md)

**계기**: 사용자 — "본인 게시물의 수정 버튼은 내용과 같이 고치는 게 아니라 첨부만 먼저 고칠 수 있게 돼 있다, 수정에 들어가서 둘 다 고치게 해 달라", "글 게시를 모달 창에서 쓰는 게 어색하다, 편집 툴·편집 UI가 따로 있어야 하지 않나". 선택지에서 "WYSIWYG 편집기"와 회원 웹 처리 "허용 목록 정화 + 두 겹 방어"를 골랐다.

**한 일**:
- api: `posts/post-content.ts` — `sanitize-html` 허용 목록 정화(태그 16종, `a`의 `href`만·http(s)/mailto, 링크 `target`/`rel` 강제), 평문 입력은 `<p>` 줄로, 인라인 태그로 시작한 결과는 `<p>`로 감쌈(화면이 블록 태그로 HTML을 알아본다), 글자 유무 판정. `PostService` 생성·수정이 저장 전에 거르고 빈 본문은 400 `POST_CONTENT_EMPTY`.
- admin-web: 글쓰기 `/board/new`·수정 `/board/:id/edit` 화면(`PostEditorPage`, 지연 로딩) — 제목·카테고리·대상 지점/회원 공개(본사)·대상 시설(지점)·서식 편집기(`RichEditor`, TipTap v3 도구 막대 13개)·첨부. 새 글 첨부는 골라 두었다가 등록 직후 올린다(`lib/post-attachments.ts`의 `uploadAttachment`로 상세 첨부 칸과 공유). 게시판의 모달과 상세의 인라인 편집 폼을 지웠다. 상세 본문은 `RichContent`(DOMPurify, 예전 평문 글은 글자). 도움말 2화면 추가·문구 갱신, 오류 해결 문구 `POST_CONTENT_EMPTY`.
- member-web: 공지 상세가 서식 본문을 DOMPurify로 거른 HTML로 그린다(평문 글은 그대로). 서식 CSS.
- e2e: `admin-branch` 공지 테스트를 작성 화면 → 굵게 → 시설 → 첨부 골라 등록 → 상세 → 수정 화면 순으로 바꿨다. `member-notice`는 본문에 `script`·`javascript:` 링크를 넣어 화면에 남지 않고 실행되지 않음을 본다.
- 문서: [D62](../decisions/D62.md), 게시판 ADR-BRD-06·§11·요약 카드, 개발보안 점검표 입력-4·보안관리계획 S5 문구(이제 본문 HTML을 그린다), 라이선스 목록 재생성.

**근거**: D62(D41 재고 트리거 검토 — 쿠키 전환 대신 허용 목록, 인증 변경 없음), ADR-BRD-04(첨부), ADR-BRD-05(시설), D60(작성·수정 권한 숨김). `sanitize-html`은 2.18.1 유지 — 2.17.x 이하에 XSS 권고가 있다. 그 대신 ESM 전용 `htmlparser2` 12를 jest가 변환하도록 `transformIgnorePatterns` 예외를 넣었다(실측: `nest build` 결과물을 Node 22로 `require`해 정화 동작 확인). 번들(실측): 관리자 웹 처음 묶음 502KB, 편집기 묶음 413KB(gzip 133KB) — 지연 로딩 전에는 한 묶음 914KB였다.

**검증**: api lint·tsc, jest 50개 파일 541건 통과(`post-rich-content` 6건 신규 — 인라인 태그로 시작한 본문을 문단으로 감싸는 건은 전체 실행 뒤 추가해 그 파일만 다시 돌림). admin-web·member-web lint·빌드 통과. 화면 자동 테스트 10건 통과(`npm run e2e`). 첫 실행에서 수정 화면 줄바꿈 뒤 굵게가 이어져(편집기의 정상 동작) 테스트가 굵게를 끄도록 고쳤다. 편집기의 목록·인용·링크 도구와 배포 화면은 **검증되지 않음**(Worker 재배포 뒤 확인).

**커밋**: `apps/api`(post-content·서비스·jest 설정·spec·의존성), `apps/admin-web`(작성·수정 화면·편집기·본문 보기·첨부 공용 함수·라우트·도움말·CSS), `apps/member-web`(공지 상세·정화·CSS), `e2e/tests` 2개, docs.
