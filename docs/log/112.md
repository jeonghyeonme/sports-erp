**계기**: 발표에서 "RFP대로 하라"는 지적을 받았다(사용자). RFP 원문(1~7쪽)을 다시 대조해 우리가 바꾼 범위(앱 → 모바일 웹, 98 → 83곳, 세부 권한 → 역할 4개)와 미구현을 정리했고, 사용자가 비용이 작은 묶음부터 시작하기로 했다. 사용자 결정 2건: "페이지 위치 정보를 MAP형태로" = 경로 표시, 지점은 98곳으로 되돌리지 않고 5곳 고밀도 + 규모 설계(D51).
