**계기**: 브리프 B1-3. B1-2([083](083.md))를 마친 뒤 사용자가 세 가지를 정했다(2026-10-08).

**한 일**

1. **지난 회차 예약 차단(ADR-RSV-05, api)**
   - `POST /reservations`는 회차 시작 시각(KST)이 지금 이전이거나 같으면 409 `SLOT_ALREADY_STARTED`를 낸다. 검사 순서는 계약 종료 다음, 중복 앞이다.
   - 시작 시각 계산은 취소 마감과 같은 함수(`kstSlotStart`)를 쓴다.
   - 테스트를 3건 추가했다: 지난 날짜 409(예약 행 없음), 오늘이지만 1시간 전 시작 409, 대조군 1시간 뒤 201.
   - **테스트 데이터 정리**: 시드 회차 2건이 2026-09-21·22로 고정돼 있어, 그동안 여러 spec이 지난 회차를 예약하고 있었다. 워커 DB를 만들 때마다 이 두 회차를 오늘(KST) +7일·+8일로 옮긴다(`test/setup/test-db.ts`의 `moveSeedSlotsToFuture`, globalSetup과 `resetWorkerDb`에서 호출). 기준 DB와 시드 원천은 그대로다.
   - "마감 이내 취소는 환불 없음" 테스트는 예약한 뒤 회차 날짜를 과거로 돌리도록 바꿨다. 기대값은 그대로다.
2. **`GET /posts?sort=latest`(ADR-BRD-03, api)**
   - 지금 목록은 오래된 글부터라, 최근 3건을 받으려면 호출이 2회 들거나 새 글이 빠진다.
   - 생략하거나 모르는 값이면 기존 순서다. 그래서 admin-web과 기존 테스트 기대값은 바뀌지 않는다.
   - 새 라우트가 아니므로 지점 격리 공격 표에는 더할 것이 없다. 테스트 2건을 추가했다.
3. **배포 DB 시연 회차(Supabase `sports-erp`, 승인된 쓰기)**
   - 넣은 회차: 서초 아침 요가, 2026-10-12 ~ 12-31 평일 07:00–08:00, 정원 15, 59건.
   - id는 `slot-seocho-yoga-YYYYMMDD`로 고정이고 `ON CONFLICT DO NOTHING`이라 다시 실행해도 같다.
   - 적용 전에 로컬 복제 DB에서 2회 실행했다. 1회차 59건, 2회차 0건이 들어갔고 지문(md5)이 같았다.
   - 적용 후 배포 DB는 61건(기존 2 + 59), 지문 `d52900cc…`로 로컬과 일치했다.
   - 기존 시드 회차 2건(예약 0건)은 건드리지 않았다.
4. **회원 웹 화면(B1-3)**
   - 홈
     - 혼잡도 카드: 자동 폴링이 없다. 화면 진입 뒤 30초가 지나야 새로고침 버튼이 다시 켜진다. "N분 전 갱신"을 함께 보인다. 단계 이름은 혼잡도관리 A-6을 따른다.
     - 최근 공지 3건.
   - 공지 목록(쪽 이동)·상세
     - 회원에게 보이지 않는 글은 404 문구를 보인다.
     - 본문은 텍스트로만 그린다(D41 재고 트리거: HTML 렌더링 금지).
   - 내 정보 탭
     - 요약 조회 1회(수강 중 건수·PT 남은 횟수 포함).
     - 이름·연락처 수정. 서버가 형식을 보지 않아서 화면에서 흔한 실수만 막는다. 저장하면 인사말의 이름도 바로 바뀐다.
     - 수강·PT 목록은 펼칠 때만 부른다.

**근거**: D40·D41, ADR-RSV-05, ADR-BRD-01·02·03, ADR-FAC-01·04, ADR-MEM-03, design-constants ⑩.

**요청 수(실측, 로컬 프로덕션 빌드)**

| 화면 | 호출 |
|---|---|
| 로그인 + 홈 | 3 (login, facilities, posts 3건) |
| 공지 목록 / 상세 | 1 / 1 |
| 예약하기 → 회차 → 예약 → 결제 → 내 예약 | 5 (B1-2와 같음) |
| 내 정보 | 1 (펼치면 수강·PT 각 +1) |
| 홈 다시 들어오기 | 2 |
| 혼잡도 새로고침 | 1회당 1, 30초에 최대 1 |
| **한 방문: 로그인 → 공지 읽기 → 예약·결제 → 내 예약 → 내 정보 → 홈** | **13** |

- 공지를 읽지 않고 홈으로 돌아가지 않으면 9회다. 가정 10회(⑩)는 넘을 수 있다. 홈 재진입(+2)과 공지(+2)가 원인이다.
- 줄이는 방법(미결정): 홈 카드 결과를 같은 방문 안에서 잠시(예: 60초) 메모리에 두면 재진입이 0회가 된다. 대신 그동안 혼잡도가 낡을 수 있다(새로고침 버튼은 남는다).
- 실제 값은 배포 후 B1-4에서 ⑩을 실측으로 바꿀 때 함께 판단한다.
