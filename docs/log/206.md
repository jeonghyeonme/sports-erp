# 206. 문서 실제 파일 업로드 — 저장소 직접 업로드·열람 기록, 옛 주소 문서 유지, 문서 목록 서버 쪽 나누기 (D69 2차, 자원문서관리 ADR-RES-05) (2026-11-08)

> [진행 로그 인덱스](README.md)

**계기**: STATUS 3번 "D69 2차 — 문서 실제 파일 업로드"를 사용자가 진행 요청. 착수 때 사용자 결정(2026-11-08): ① 스키마는 칸 추가(`storagePath`·`fileName`, `fileUrl` nullable, 둘 중 하나 CHECK) — **스키마 변경 승인** ② 올리는 규칙은 제안대로(D57 형식·한도, 지금 문서 등록 권한, 열람 기록, 문서 1건에 파일 1개) ③ 목록 일관화 2차의 남은 "문서 목록 서버 쪽 나누기"도 같이. 그 전 결정(2026-10-31): 기존 가짜 주소 문서는 그대로, 문서도 열 때 열람 기록, 보존기한이 지나면 알림만. 새 브랜치 `claude/document-files`.

**한 일**
- **마이그레이션** `20261108120000_d69_document_files`: `Document.fileUrl` NOT NULL 해제, `storagePath`(유일)·`fileName` 추가, CHECK `Document_file_source_ck`(주소·경로 정확히 하나)·`Document_stored_file_meta_ck`(올린 파일은 이름·형식·크기 필수). 새 테이블이 없어 RLS 작업은 없다. `prisma migrate diff`로 스키마와 마이그레이션이 같은지 확인.
- **API**: `POST /documents/upload-url`(문서 입력 권한, 지점 무관 — `@BranchScopeExempt`), `POST /documents`에 `file: { path, fileName }`(저장소에서 크기·형식 재확인, 트랜잭션 밖), `GET /documents/:id/open`(`@ScopedResource('document')` — 60초 URL 또는 옛 주소, 열 때마다 변경 이력 `DOCUMENT_FILE_VIEWED`, 가짜 `demo://` 주소는 409 `DOCUMENT_FILE_UNAVAILABLE`), `GET /documents` 서버 쪽 나누기·검색 `q`(제목·대상 직원)·정렬(`DOCUMENT_SORT_KEYS`) — 기본 최근 등록부터. 응답에는 저장소 경로를 넣지 않는다(`stored`·`fileName`만).
- **공통으로 모음**: 계약 파일(D69)과 문서 파일이 같은 "업로드 URL → 직접 올림 → 저장소에서 재확인" 로직을 쓰도록 `attachment-rules`에 `requestStoredUpload`·`verifyStoredFile`(경로 접두사 확인 포함)을 두고 `ContractFileService`도 그것을 쓰게 바꿨다 — 계약 파일도 이제 경로 접두사(`contracts/`)를 서버가 다시 본다. 화면도 `lib/stored-files.ts`(`uploadStoredFile`·`openStoredUrl`)로 계약 파일·문서 파일이 같이 쓴다.
- **변경 이력**: `AuditAction`에 `DOCUMENT_FILE_VIEWED`, `AuditEntity`에 `Document`(대상 이름 = 문서 제목, 지운 문서도 보인다), 변경 이력 검색이 문서 제목도 찾는다. `audit.ts` 주석의 D71 누락(STATUS 작은 것)도 고쳤다.
- **화면**: 문서함 — 등록 모달이 파일 고르기(형식·10MB 화면 확인, 제목이 비면 파일 이름으로), 목록은 서버 쪽 나누기·검색·정렬·Pager, 제목을 누르면 열기(올린 파일은 내려받기, 옛 링크는 새 탭), 파일 이름 또는 "옛 링크 문서" 표시, 삭제는 확인 창(D74). 직원 상세 인사서류도 제목을 눌러 연다(`limit=100`). 변경 이력에 "문서 열람". 화면 도움말·오류 해결 문구(`DOCUMENT_FILE_REQUIRED`·`DOCUMENT_FILE_UNAVAILABLE`·`ATTACHMENT_PATH_INVALID`·`ATTACHMENT_DUPLICATE`).
- **문서**: 자원문서관리 ADR-RES-05·요약 카드·§11·A-3·A-5·A-8, entities.md, data-integrity 제약 표.
