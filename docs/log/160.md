# 160. RFP 추적표 재대조 — log/145~159 반영 확인, 판정 그대로·낡은 근거 문구 정리와 요구사항 정의서 재생성 (2026-10-22)

> [진행 로그 인덱스](README.md)

**계기**: RFP 추적 전담 세션의 첫 작업. 추적표 판정(56/64 = 88%) 뒤 같은 날 들어온 작업(시설 공지 log/145, 세부 권한 log/146~148, 매뉴얼·교육 자료 log/152·153, 서식 편집기 D62 log/154~157, 의존성 취약점 D63·D64 log/158·159)이 [요구사항추적표](../reference/요구사항추적표.md)와 요구사항 정의서에 맞게 들어갔는지 조항마다 대조했다.

**결과**: 판정·집계는 바뀌지 않는다 — 구현 50·조정 6·부분 5·미구현 3·해당 없음 8, 전체 56/64(88%)·부분 포함 95%, 기능·성능 27/28, 시스템~제약 17/19, 과업·산출물 12/17(표에서 다시 셈). D62는 F4-3의 "글 작성"을, D63·D64는 N2-1의 "개발보안"을 보강할 뿐 부분 조항을 채우지 않는다.

**고친 것(어긋남)**:
- §1-1 게시판 행 "공지는 지점 단위(시설 지정 없음)" — log/145 이후 틀림 → 시설 지정(ADR-BRD-05)·서식 편집기(D62).
- F4-2·§2-2 게시판 "배포 저장소의 실제 파일은 검증 전" — log/144·153에서 확인됨.
- N6-4 "역할별 메뉴·버튼, 서버는 `@Roles`" — log/148 이후 세부 권한(`useCan`·`PermissionGuard`).
- N8-1·§1-2 #8 "약점 9건" → 10건(security-plan S10, D63). N10-1·§1-2 #10 "운영 의존성 219개" → 243개(log/158 재생성).
- N2-1·§1-2 #2에 의존성 취약점 대조(D63·D64), F4-3에 서식 편집기(D62).
- §2: 규모(라우트 99 → 105, 관리자 웹 화면 경로 21, api 테스트 50개 파일 541건)와 "두 웹 자동 테스트 없음"(D59 이후 틀림)을 2026-10-22 실측으로.
- §2-3에 부분 조항 T3-2(검수·도입)·N8-2(업무위탁 계약)가 빠져 있었다 — §3 판정 기준이 "빠진 부분은 §2-3"인데 3행뿐이라 요구사항 정의서 "미구현" 시트도 3행이었다. 5행으로.
- §3-0 읽는 법(매뉴얼이 아직 감점 요인처럼 적힘)·§4 결론(실운영 조건 항목 추가).
- 요구사항 정의서: log/153 이후 재생성되지 않아 게시판 시트에 ADR-BRD-06(D62)이 없었다 → `scripts/deliverables/requirements.py`로 재생성(라우트 103 — `dev-storage` 제외, 총괄 176행).

**검증**: 판정 수는 추적표 §3 표를 스크립트로 다시 셈. 재생성한 xlsx에서 게시판 시트 ADR-BRD-06·D62, 미구현 시트 GAP-01~05, 충족 판정 시트 243 확인. doc-check 통과. 코드 변경 없음.
