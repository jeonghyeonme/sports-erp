# 29. Supabase에 스키마만 우선 배포했다 — 실DB 전환의 첫 단계 (2026-09-27)

> [진행 로그 인덱스](README.md)

**계기**: 사용자가 "인프라에 올리는 것부터 하고 싶다"며 이미 연결해둔 Supabase MCP 커넥터로 DB를 시도해보고 싶다고 요청. CLAUDE.md가 "MockDataService→실DB 전환은 사용자 승인 필요(ADR 대상)"로 명시해둔 결정이라, 범위부터 사용자에게 확인했다 — **API를 지금 바로 Prisma로 전환**할지, **스키마만 먼저 배포**해서 인프라를 준비만 해둘지. 사용자가 후자를 선택했다("오늘 안에 끝남, 지금 도는 앱을 안 건드림" 쪽).

**한 일**: 기존 Supabase 프로젝트 3개(`Portfolio Website Structure`·`Portfolio Site V2`·`Kmong_Dev`)는 전부 이 앱과 무관한 다른 용도라 재사용하지 않고, `sports-erp` 신규 프로젝트를 만들었다(조직 `jeonghyeonme's Org`, free 플랜, 리전 `ap-northeast-2`/서울, 프로젝트 ref `blbjnozojvromktprqhv`). `apps/api/prisma/schema.prisma`에서 `npx prisma migrate diff --from-empty --to-schema-datamodel schema.prisma --script`로 SQL을 뽑아(이 컨테이너에서 DATABASE_URL로 직접 Postgres에 붙는 것보다, Supabase MCP의 `apply_migration`으로 관리 API를 통해 적용하는 쪽이 네트워크 정책상 더 안정적이라 이 경로를 택함) 27개 테이블을 전부 생성했다.

**스키마 드리프트 발견**: 이 과정에서 `schema.prisma`가 실제 `MockDataService` 현실보다 낡아 있다는 걸 확인했다 — **자원문서관리 도메인의 `Asset`·`Document` 모델이 Prisma 스키마에 아예 없다**(2026-09-19에 mock에만 추가되고 스키마엔 반영 안 됨). `CourseEnrollment.status` enum도 스키마는 `ACTIVE`/`EXPIRED` 2종인데 mock은 `ACTIVE`/`COMPLETED`/`CANCELLED` 3종으로 다르다(2026-09-26 D3 작업 때 스키마 갱신을 빠뜨림). 지금은 "스키마만 배포"가 범위라 스키마 자체를 고치지 않고 있는 그대로 배포했다 — 실제 전환 작업 시작 전에 스키마를 mock과 다시 맞추는 게 먼저 할 일로 남는다.

**보안 확인**: 테이블 생성 직후 Supabase 자체 어드바이저리가 27개 테이블 전부 RLS(Row Level Security) 비활성 상태라고 경고했다. 이 프로젝트는 Supabase 클라이언트 라이브러리(anon key)를 전혀 쓰지 않고 NestJS가 `DATABASE_URL`로 Postgres에 직접 붙는 구조라 당장 기능은 안 깨지지만, anon key가 어디선가 실수로 노출되면 PostgREST를 통해 27개 테이블이 전부 읽기/쓰기 가능해진다 — 애초에 이 프로젝트가 PostgREST 경로 자체를 쓸 계획이 없으므로 정책 없이 RLS만 켜는(=REST 경로를 통째로 막는) 게 안전한 기본값이라고 판단했지만, 이건 사용자 승인 없이 자동 적용하지 않고 SQL만 제시했다(Supabase MCP 자체 가이드라인이기도 함).

**검증**: `list_tables`로 27개 테이블·컬럼·FK가 스키마 그대로 반영된 것 확인. 아직 `apps/api`는 이 DB를 전혀 쓰지 않는다 — "연결은 됐지만 사용 중은 아님" 상태이며, 이 사실을 사용자에게 명시적으로 전달했다. **추가(같은 날)**: 사용자가 "정책 없이 RLS만 켜기"를 선택해 27개 테이블 전부 `ENABLE ROW LEVEL SECURITY` 적용, `list_tables`로 전 테이블 `rls_enabled: true` 재확인.

**커밋**: 코드 변경 없음(원격 Supabase 프로젝트에만 DDL 적용). 이 로그 절 자체가 이번 변경의 유일한 저장소 기록이라, 다음에 실제 Prisma 전환에 착수할 때 이 절부터 읽을 것.
