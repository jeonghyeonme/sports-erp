# 120. RFP 중간 작업 M5·M6·M8 — 예약 달력 보기, 목록 CSV 출력, 느린 요청 안내 (2026-10-16)

> [진행 로그 인덱스](README.md)

**계기**: 작업 브리프 B2 권장 순서 넷째 묶음(D51). 요구사항추적표 §2-3의 세 행 — UI/UX "캘린더/스케줄표형 예약"(1-2 #6), 권한관리 "출력"(1-1 #1), 시스템성능 "느린 작업 사전 알림"(1-1 #11). 화면 위주라 API 변경은 없다.

**결정 방식**: D53(상위 목표 → 답안지 → 핵심 변수)을 처음 적용했다. 질문마다 핵심 변수와 레퍼런스를 함께 냈고, 사용자는 네 질문 모두 추천안을 골랐다. **사용자 설명은 남기지 않았다**(메모 없음) — D53 결정 4의 "사용자의 설명"은 이번엔 비어 있다.

**사용자 결정(2026-10-16)**: M5 회원 웹 + 관리자 둘 다 / M6 회원·근태 요약·결제 CSV, 마스킹 유지 / M6은 세부 권한과 따로(역할 기준) / M8 3초 안내 + 15초 재시도 제안.

**한 일**:
- M5(예약및결제 ADR-RSV-06): 회원 웹 회차 화면에 날짜 띠(오늘부터 2주~마지막 회차 날, 점·비활성, 고른 날만 — 추가 호출 0). 관리자 예약 관리에 "주간 시간표"(`components/WeeklyTimetable.tsx`, 월~일, 회차 시각·프로그램·예약 수/정원, 이전·다음·이번 주) — 회차 예약형 프로그램마다 기존 회차 API(회차 관리와 같은 캐시).
- M6(D54): `lib/csv.ts`(BOM·따옴표·수식 주입 방지·쪽 단위 전체 모으기 최대 5,000행)·`lib/export-columns.ts`·`components/ExportCsvButton.tsx`. 회원(지금 조건 그대로 전체)·결제 내역·지점 근태 요약·본사 근태 현황에 버튼. 전화번호는 목록 API의 마스킹 값 그대로.
- M8(D55): 두 앱 `lib/slow-requests.ts`(요청 추적·3초/15초 단계)·`components/SlowRequestNotice.tsx`(앱 최상위), axios 인터셉터에서 시작·끝을 잰다. 회원 웹은 401 재시도 인터셉터보다 먼저 등록.
- 도움말(`help-content.ts`) 회원·근태·예약 문구.

**구현 중 발견**: 한글 파일 이름(`회원_2026-10-16.csv`)이 헤드리스 Chromium에서 `download`로 바뀌었다(영문 이름은 그대로). 실제 브라우저에서도 그런지는 확인하지 않았지만 영문 이름으로 바꿨다(D54 결정 4). 같은 확인 중 blob URL을 클릭 직후 해제하던 것도 1초 뒤 해제로 바꿨다.

**근거**: D51, 예약및결제 ADR-RSV-06, D54, D55, D53(결정 방식), ADR-MEM-04·D47(마스킹·열람), D43(쪽 단위), D49·D50(콜드 스타트·처리 시간), design-constants ⑩.
