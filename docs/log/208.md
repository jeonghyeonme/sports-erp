# 208. 운영 실적 시각화 — 대시보드 숫자 카드·월별 차트·지점 비교, 지점 상세 13개월 차트(D75) (2026-11-08)

> [진행 로그 인덱스](README.md)

**계기**: STATUS 다음 할 일 "시각화(log/197 A-5)" — 사용자가 진행 요청. 착수 때 사용자 선택: 범위 = 본사 대시보드·지점 상세·지점 관리자 대시보드 모두, 도구 = 직접 그린 SVG, 영업 리포트(차별화전략 §2)는 이번엔 빼고 차트만. 새 브랜치 `claude/visualization`.

**한 일**
- **D75 결정**과 dataviz 스킬 절차(형태 → 색 → 검사 스크립트 → 표시 규격 → 툴팁 → 표로 보기 → 화면으로 확인)를 따랐다.
- **API**: `GET /branches/:branchId/performance?months=`(1~13, 기본 3 그대로 — 기존 호출 영향 없음), 새 `GET /branches/performance`(본사 전용) = 전사 월별 추이(모든 지점 합) + 지난달 지점별 순매출(큰 것부터). `branch-performance.ts`의 집계를 "한 지점 또는 전사" 조건 조각으로 바꿔 같은 쿼리 4개를 그대로 쓴다(D48 왕복 수 유지).
- **차트 부품**(`components/charts/`): `MonthlyColumnChart`(월별 세로 막대, 진행 중 달은 옅게 + "진행 중", 칸 폭에 맞춰 다시 그려 글자 크기 유지 — `lib/use-element-width.ts`), `RankedBarChart`(가로 막대), `Sparkline`, `PerformanceCharts`(지표 4장 + 표로 보기)·`PerformanceStatTiles`(지난달 값·전달 대비·12개월 추세선). 눈금·표기 `lib/chart-scale.ts`.
- **화면**: 본사 대시보드 — 숫자 카드 줄(지점 표 위), 전사 월별 차트 4장 + 지난달 지점별 순매출(지점 표 아래). 지점 관리자 대시보드 — 자기 지점 숫자 카드·차트(지점 조회 권한일 때). 지점 상세 — 3개월 표를 13개월 숫자 카드·차트·표로 보기로.
- **색 검사**(`validate_palette.js`): 브랜드 teal-700 `#0f766e`는 채도 하한 미달(0.086 < 0.1, 회색으로 읽힘) → 차트 표시는 teal-600 `#0d9488`(밝기·채도·대비 통과). 진행 중 옅은 단계는 대비 3:1 미만이라 "진행 중" 글자와 표로 보기를 함께 둔다. 관리자 웹은 어두운 화면이 없어 밝은 화면만.
- **화면으로 확인하며 고친 것**(시연 데이터 층으로 캡처): 세로축 눈금이 왼쪽에서 잘림(여백을 가장 긴 눈금 글자로 계산), 순매출 카드 값이 두 줄("32,629,000 원" → "3,263만원", 전체 값은 마우스를 올리면), 차트 3+1 배치(2열로), 진행 중 막대 위 숫자가 옆 막대와 겹침(막대 위 숫자 없앰 — 카드·툴팁·표에 있다), 달 라벨 "12월'26.1월" 겹침(칸이 좁으면 이번 달부터 거꾸로 하나 걸러), 증감 0일 때 문장 어색.
- 화면 도움말(대시보드·지점 상세), 디자인시스템 §3·§5·§6.
