# 172. 관리자 웹은 직원 계정만 — 회원 로그인을 막고 회원 웹으로 안내 (2026-10-22)

> [진행 로그 인덱스](README.md)

**계기**: 혼잡도 개선을 이야기하다 사용자가 "관리자 웹에서도 회원으로 로그인되는 게 어색하다, 회원 기능은 전부 회원 앱으로 돌리자"고 했다. 관리자 웹의 회원 로그인은 회원 웹(D41)이 생기기 전의 대용 화면이다. 결정은 [D66](../decisions/D66.md).

**한 일(admin-web만, api 변경 없음)**:
- `lib/auth-context.tsx` — 로그인 응답의 역할이 MEMBER면 받은 갱신 토큰을 `POST /auth/logout`으로 바로 폐기하고 세션을 만들지 않은 채 "회원 계정은 관리자 웹에서 쓸 수 없습니다 / 해결: 아래 회원 앱에서…" 오류를 보인다.
- `LoginPage` — 부제 "본사·지점 관리자 웹", 아래에 "회원이신가요? 회원 앱에서 로그인 →"(`/m/`). `lib/demo-account.ts`에서 회원(이수진) 데모 버튼 삭제(직원 4개).
- 회원용 화면 코드 삭제 — `AppLayout` 회원 메뉴 5개, `help-content` 회원 안내 5곳, `ReservationsPage`의 회원 모드(예약 가능한 프로그램 카드·내 예약·`ProgramSlotsCard`·`MockPayButton`).
- 화면 자동 테스트 `e2e/tests/admin-staff-only.spec.ts` — 데모 버튼 4개·회원 없음, 회원 계정 로그인 시 로그인 화면에 머물고 안내·`/m/` 링크.

**근거**: D66(대안: 그대로 / 화면에서 막기 / 서버에서 막기 — 로그인 API는 앱을 구분하지 못하고, 회원 API는 회원 웹이 같은 것을 쓰므로 서버 차단의 보안 이득이 없다), D41 결정 5(반대 방향).

**검증**: admin-web lint(경고 0)·빌드. 화면 자동 테스트 로컬 전체 통과(새 테스트 포함 — 처음 파일명이 `admin-member-…`라 회원 프로젝트 패턴에도 걸려 두 번 돌아 `admin-staff-only`로 바꿈, 12건). 로컬 dev 서버에서 회원 계정으로 로그인 → 로그인 화면 유지·안내 표시를 캡처로 확인하고, 그 계정의 갱신 토큰이 1행 늘었는데 폐기 안 된 행 수는 그대로(3 → 3)인 것을 DB에서 확인. 배포 화면은 Worker 재배포 전이라 검증되지 않음.

**남은 것**: 사용자 매뉴얼(Word)은 화면 도움말에서 생성하므로 다음 재생성 때 회원 안내가 빠진다(이번엔 재생성하지 않음). Worker 재배포(사용자).
