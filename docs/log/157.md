# 157. 편집기 사용성 — 고른 부분만 제목, 링크는 편집기 안 입력칸 (2026-10-22)

> [진행 로그 인덱스](README.md)

**계기**: 사용자가 배포 화면에서 글을 써 보고 두 가지를 지적했다 — ① 제목·소제목을 넣으면 글 전체에 적용된다 ② 링크 주소를 크롬 팝업(`window.prompt`)으로 받는다.

**원인**: ① 제목은 문단(블록) 단위 서식이라, Enter 없이 한 문단으로 쓴 글에서 일부를 골라 눌러도 그 문단 전체가 제목이 됐다(TipTap 기본 동작). ② log/154에서 링크 입력을 `window.prompt`로 빠르게 만들었다.

**한 일**(D62 · 게시판 ADR-BRD-06 범위 안, 결정 변경 없음):
- `RichEditor` `blockStyle` — 한 문단 안의 일부를 고르고 제목·소제목을 누르면 고른 범위의 앞뒤를 `splitBlock`으로 끊고 가운데만 바꾼다. 커서만 있으면(고른 글자 없음) 그 문단 전체 — 워드·한글과 같다. 줄바꿈(Shift+Enter)으로 이은 줄은 한 문단이라 함께 바뀐다(감수).
- 링크 입력칸 — 도구 막대 아래에 주소 칸 + 적용·링크 빼기·취소, 잘못된 주소는 칸 아래 안내(alert 없음). 열 때의 선택 범위를 기억해 적용하고, 고른 글자가 없으면 주소를 링크 글자로 넣는다. Enter는 바깥 글쓰기 form을 제출하지 않게 막고, Esc는 닫는다.
- 도움말(작성 화면) 두 줄, CSS.

**검증**: admin-web lint·빌드. 화면 자동 테스트 10건 통과 — `admin-branch`에 "한 문단에서 앞 6글자만 골라 제목 → `h2`는 그 글자만, 나머지는 문단", "링크 칸에 `javascript:` → 안내, https 주소 Enter → 작성 화면 그대로·본문 `a href`", 상세에서 `h2`·`a href` 확인을 더했다. 목록·인용 도구와 배포 화면은 **검증되지 않음**(Worker 재배포 뒤 사용자 확인).
