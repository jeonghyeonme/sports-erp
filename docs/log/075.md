# 075. Render `sports-erp-api` 일시정지 — Lambda 전환(D37) 정리 (2026-10-06)

> [진행 로그 인덱스](README.md)

**계기**: Lambda 전환 뒤 Render는 롤백용으로만 켜 두었다(트래픽 없음). 발표자료를 마무리한 뒤 정리하기로 했던 일이다.

**한 일**(사용자): Render 대시보드에서 `sports-erp-api`를 일시정지(Suspend)했다. Claude는 대시보드 절차와 사전·사후 확인 항목을 안내했다. Render MCP는 작업공간이 선택돼 있지 않아 서비스 상태를 직접 조회하지 않았다.

**근거**: [D37](../decisions/D37.md) R11 — Render는 9/28 D26 코드에 멈춰 있어 되돌릴 대상이 아니다. 롤백은 Lambda 별칭 `live`를 이전 버전으로 옮기는 것으로 한다.

**함께 정리한 STATUS 항목**
- "Render는 아직 켜져 있다" → 일시정지.
- 할 일 "AWS 배포 역할 신뢰 정책에서 `main-5x9td9` 빼기": 사용자가 이 세션 앞부분에서 마쳤다고 알려 왔으나 STATUS에 남아 있어 지웠다. Render 연결 브랜치 변경은 정지로 불필요해졌다.
- 열린 위험 "노출된 비밀값": 이제 DB 비밀번호를 쓰는 곳은 Lambda뿐이다. 교체 절차는 그대로 둔다.
- 남은 선택 작업: 폐기된 `sports-erp-web` 삭제(사용자).

**검증**: 사용자 확인(대시보드 상태). Claude 쪽에서는 검증되지 않음. 정지 후 Worker 주소 로그인 확인 여부는 기록되지 않았다.

**커밋**: STATUS, `aws-lambda/README.md` §8 체크리스트, 이 로그.
