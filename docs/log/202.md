# 202. 목록·확인 창 일관화 1차 — 머리글 정렬·치는 대로 검색·확인 창·모달 접근성(D74) (2026-11-08)

> [진행 로그 인덱스](README.md)

**계기**: STATUS 다음 할 일 "목록 일관화"(log/197 A-1~A-4·B-1·B-3) — 사용자가 진행을 요청. PR #143 병합 뒤 `dev`에서 새로 시작.

**한 일**
- **D74 결정**: 1차는 API·권한 변경 없이 화면만. 2차(CSV 확대 = 권한 카탈로그 변경, 서버 목록 정렬·검색 인자, 문서 서버 쪽 나누기)는 사용자 선택으로 남겼다.
- **머리글 정렬**: `lib/table-sort.ts`(`sortRows`·`useSortState`), `components/SortTh.tsx` — 직원(`StaffPage`)·프로그램·강사·문서 표. 지점별 묶음 화면은 정렬 상태 하나를 모든 묶음에 쓴다. 프로그램 상태는 진행 순서(준비 → 운영 → 휴강 → 종료), 강사 상태는 활동 → 비활성.
- **회원 목록 검색**: "검색" 버튼 제거, 0.3초 뒤 서버 검색(Enter는 바로).
- **확인 창**: `components/ConfirmModal.tsx` — 시설 운영 중단(`FacilitiesPage`)·계약 파일 실물 이관(`ContractRounds`)·보존 끝난 파일 정리(`ContractRetentionPage`)의 `window.confirm` 3곳을 바꿨다. 관리자 웹에 `window.confirm`·`window.alert`가 더는 없다.
- **모달 접근성**(`components/Modal.tsx`): `role="dialog"`·`aria-modal`·`aria-labelledby`, 열 때 초점 이동(안쪽 autoFocus가 있으면 그대로), Esc 닫기, 닫으면 연 버튼으로 초점 복귀. 모든 모달(회원 등록·직원 채용·회차 등록 등)에 함께 적용된다.
- **화면 자동 테스트 2건 추가**(19건): 프로그램 머리글 정렬(오름·내림, `aria-sort`), 시설 운영 중단 확인 창(Esc 취소 → 실행 → 되돌리기). 회원 등록·검색 테스트에서 검색 버튼 누름을 뺐다.
- 측정하며 본 것: 처음엔 `th`에 `scope`가 없어 Playwright(접근성 트리)가 머리글을 칸(cell)으로 읽었다 — `scope="col"`을 붙여 `aria-sort`가 열 머리글에 붙게 했다.

**근거**: D74, log/197, D43(서버 쪽 나누기), D60(출력 권한 — 2차), D72(빠른 찾기와 같은 검색 동작), 디자인시스템 §3(정렬 머리글)·§5(확인 창).
