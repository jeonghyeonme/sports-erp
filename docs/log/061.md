# 061. 요구사항 정의서·데이터 정의서를 엑셀로 만들었다 — 저장소에서 생성하는 스크립트로 (2026-10-05)

> [진행 로그 인덱스](README.md)

**계기**: 사용자가 Proposal·요구사항·데이터·설계를 HTML이 아닌 사무용 문서(Word·Excel)로 따로 두자고 했다. 요구사항과 데이터처럼 표가 본체인 문서는 Excel로 하기로 했고, 엑셀부터 만든다. HWP는 필요 없고, 기존 HTML 산출물(5-1·5-2)은 Word 문서가 나오면 대체한다.

**한 일**: 손으로 쓰면 코드와 금방 어긋나서(D38 "한 사실은 한 곳에만"), 저장소를 원천으로 생성하는 스크립트를 만들었다.
- `scripts/deliverables/data_definition.py` → `docs/deliverables/데이터정의서.xlsx`
  - 원천: `schema.prisma`, 마이그레이션 SQL
  - 시트: 표지, 테이블 목록, 컬럼 정의, 관계, 코드 정의, 인덱스·유일, DB 규칙
  - 규모: 테이블 31, 컬럼 264, enum 24, FK 42, CHECK 18, 트리거 7
  - 주석이 없는 컬럼 108개는 용어 사전(GLOSSARY)으로 설명을 채웠다. 테이블 논리명은 TABLES에 둔다.
  - **미사용 테이블 7개**를 표시했다: AuditLog, Attachment, PostReadReceipt, StaffProfileChangeRequest, ProgramScheduleTemplate, CongestionSnapshot, FacilityCheckIn. 코드(테스트·mock 제외)가 읽거나 쓰지 않는 테이블이다.
- `scripts/deliverables/requirements.py` → `docs/deliverables/요구사항정의서.xlsx`
  - 원천: 도메인 문서(§0 사용자 스토리, §1 원문 요구·불변규칙, 요약 카드의 ADR·테스트·미구현)와 [요구사항추적표](../reference/요구사항추적표.md)(§1, §2-3, §2-4)
  - 기능 명세는 **실제 컨트롤러 라우트 78개**에서 뽑았다. 권한은 `@Roles`·`@Public`에서 읽었다. 화면 유무는 관리자 웹이 부르는 경로로 판정했다. 설명(ROUTE_DESC)만 사람이 썼다.
  - 집계(총괄 시트): 기능 78 = 화면 있음 66 + 화면 없음 11 + 화면 불필요 1. 불변규칙 26, RFP 미구현 8.
- 공통 서식은 `scripts/deliverables/xlsx_style.py`.

**근거**: D38, [060](060.md)(추적표 재실측).

**검증**:
- 두 파일 모두 LibreOffice로 수식을 재계산했다. 오류 0건이다. 집계 값은 스크립트 계산과 대조했다(컬럼 합계 264, 기능 78).
- 이 환경에는 LibreOffice Calc가 없어서 `libreoffice-calc`를 설치한 뒤 재계산했다.
- 화면 판정은 문자열 매칭이라, 경로를 변수로 조합하는 화면이 있으면 놓칠 수 있다. 결과는 추적표 §2-3 목록과 일치했다. 추가로 파견 이력 조회와 결근 미리보기도 화면이 없는 것으로 확인됐다.
- Excel·한셀에서 직접 열어 서식을 확인하지는 않았다.

**커밋**: 스크립트 3개, 엑셀 2개, README 산출물 표, 이 파일.
