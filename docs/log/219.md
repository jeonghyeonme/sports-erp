# 219. 회원 앱 PT 패키지 구매와 PT 회차 예약 — 예약 때 1회 잡고 체크인 때 차감, 현장 판매 유지 (예약및결제 ADR-RSV-09) (2026-11-09)

> [진행 로그 인덱스](README.md)

**계기**: 11주차 덱의 PT 패키지 등록 장을 보던 사용자가 "회원 앱으로 PT를 사면 직원이 따로 등록해 줘야 하나" 물었다. 확인 결과 회원 앱에는 PT 구매가 없고(내 정보에서 횟수 보기만), PT 회차는 예약 대상이 아니었다(`NOT_RESERVABLE`, PT 패키지 결제는 A-8 범위 제외). 사용자: 현장 결제 기능은 남기되 회원 앱으로도 PT 예약·결제가 되어야 한다 — 원래 있었어야 할 기능이라 발표자료에는 넣지 않는다. 스키마 변경 승인. 정할 것 셋(상품·차감 시점·노쇼)은 추천안대로.
