**작성 중 부딪힌 것**:
- Playwright는 webServer를 globalSetup보다 먼저 띄운다 — DB 초기화를 globalSetup에 두었더니 api가 없는 DB로 떠서 실패했다. 초기화를 api 시작 명령 앞(`reset-db.mjs && node dist/main.js`)으로 옮겼다. `prisma migrate reset`은 시드 설정이 `apps/api/package.json`에 있어 루트에서 시드를 못 불러 따로 부른다.
- 설정 파일이 CommonJS로 변환돼 `import.meta.url`이 안 된다 — `__dirname`.
- 관리자 웹 폼의 `<label>`이 입력과 연결돼 있지 않아 라벨로 입력을 못 찾는다(접근성 결함이기도 하다 — 화면 낭독기가 입력 이름을 읽지 못한다). 테스트는 `.field` 묶음 안에서 찾는 도우미로 우회했다. 고치는 일은 따로 남긴다.
- 회원 예약 테스트가 혼자서는 통과하고 전체로는 실패했다 — 다른 테스트가 만든 더 가까운 회차 때문에 날짜 띠가 다른 날을 먼저 골랐다. 날짜를 직접 고르게 했다. 처음 쓴 취소 확인은 "취소" 글자만 찾아 확인 시트를 누르지 않고도 통과하고 있었다 — 시트 확인 → "취소·환불"로 고쳤다.

**검증**: 로컬 7건 두 번 연속 통과(약 19초, 서버 기동 포함 약 45초). 회원 웹 첨부 표시를 일부러 꺼서 `member-notice`가 실패하는 것을 확인한 뒤 되돌렸다. e2e 타입 검사 통과. CI 잡은 이 PR에서 처음 돈다.
