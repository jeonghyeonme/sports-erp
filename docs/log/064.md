**계기**: PR #15(log/056~062)를 rebase 병합한 뒤, 사용자의 GitHub Desktop pull이 충돌했다. 로컬 `main-5x9td9`에 push하지 않은 커밋 `b06e51e`(10/4, Lambda 운영 전환 경위와 k6 실측)가 있었다. 이 커밋이 같은 번호 `log/056`, `docs/STATUS.md`, `docs/log/README.md`를 원격과 다르게 고쳐서 충돌한 것이다.
