**계기**: log/144~149의 화면 변경을 사용자가 Worker로 재배포했다.

**확인**: 배포된 관리자 웹·회원 웹 번들 해시가 `dev` `aa55530` 로컬 빌드와 같다. 데모 계정으로 운영 화면을 읽기만 했다(운영 데이터 변경 없음, 실패한 api 요청 0) — 처리 대기함(본사 4항목·서초 관리자 2항목·직원 2항목), 권한 관리 "역할 기본 권한" 39칸 전부 켜짐, 김민수 개인 권한 39칸 전부 가능, 회원 등록·CSV 버튼 표시, 공지 글쓰기 대상 시설(지점 전체 + 서초 시설 4), 회원 웹 공지 시설 고르기. 관리자 웹 공지 이미지 미리보기는 세션이 supabase.co에 닿지 못해 사용자가 브라우저로 확인했다(보임).
