**계기**: 엑셀 산출물([061](061.md))에 이어 사용자가 Word 문서 두 개를 요청했다. 옛 HTML 산출물(5-1 기업분석자료, 5-2 개발작업계획서)은 Word로 대체하기로 사용자가 승인했다.
