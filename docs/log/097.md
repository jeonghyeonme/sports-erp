# 097. 회원 웹 로그인에 데모 회원 버튼 (2026-10-10)

> [진행 로그 인덱스](README.md)

**계기**: 사용자가 회원 앱 로그인도 관리자 웹처럼 버튼 하나로 들어가게 해 달라고 했다(시연용).

**한 일**
- 회원 웹 로그인 화면 아래에 "데모 회원으로 둘러보기 (이수진 · 서초점 회원)" 버튼을 넣었다. 누르면 입력란을 채우고 바로 로그인한다.
- 계정은 관리자 웹 데모 버튼과 같은 `lee.sujin@example.com` / 공통 데모 비밀번호다(`lib/demo-account.ts`의 `DEMO_MEMBER`).
- 회원 데모 계정은 이 하나뿐이다. 이 계정은 api `DEMO_ACCOUNT_IDS`에 있어 비밀번호를 바꿀 수 없으므로(log/091) 버튼이 깨지지 않는다. 다른 시드 회원은 비밀번호 변경이 막혀 있지 않아 버튼에 넣지 않았다.

**검증**
- member-web lint·타입체크 통과.
- 로컬 api + vite를 Playwright iPhone 13 에뮬레이션으로 확인했다. 버튼을 누르면 홈("이수진님, 안녕하세요")으로 이동한다.
- **검증되지 않음**: 배포. Worker를 다시 배포해야 보인다.
