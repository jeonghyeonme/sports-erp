# 148. 세부 권한 3단계 — 적용 권한을 내려 관리자 웹이 메뉴·버튼·CSV를 숨김, F1-2·N7-2 구현(D60) (2026-10-21)

> [진행 로그 인덱스](README.md)

**계기**: log/147(2단계 — 본사 관리 API·화면) 뒤 사용자가 3단계 진행을 요청했다. 스키마 변경 없음.

**한 것**:
- api: 로그인·`/auth/me` 응답 사용자에 `effectivePermissions`(`feature:ACTION` → 허용, 지점 관리자·직원의 상한 안 칸만 — 개인 예외 → 역할 기본값 → 허용). 본사·회원은 없다. 개인 예외 원본(`permissions`)은 응답에서 뺐다. `PermissionService.effective()`.
- 관리자 웹 `useCan()`(`lib/use-can.ts`, 표에 없는 칸은 true): 메뉴(회원·프로그램·강사·예약·게시판·시설·자산·문서·업무지원 요청 — 조회 권한), 등록 버튼(회원·프로그램·시설·자산·문서·강사·글쓰기·업무지원 요청), 수정·삭제·상태(회원 정보·상태·수강/PT, 프로그램 수정·상태·종료, 시설 인원·운영, 자산 수정·상태, 강사 비활성/활성, 글 수정·삭제·첨부, 예약 체크인·취소, 휴가 승인·반려, 결근 확정, 근태 정정, 직원 정보 수정, 인사 변경 신청 승인함). CSV 버튼은 `feature`가 꺼지면 숨기고, 내려받기는 `?export=true`로 불러 서버가 출력 권한을 본다(회원·결제·근태 요약 — 근태 요약은 화면 캐시 대신 다시 받는다).
- 로그인한 채로 본사가 바꾸면 창으로 돌아올 때(focus) `/auth/me`로 다시 받는다. 판정은 서버라 갱신이 늦어도 버튼만 늦게 사라진다.
- 추적표: F1-2·N7-2 부분 → 구현. 전체 81% → 84%(54/64), 기능·성능 93% → 96%(27/28), 시스템~제약 84% → 89%(17/19). 남은 부분 7·미구현 3은 콘솔(F10-2)·문서(T4-1·P4·P5·T3-2)·실운영 조건(N7-3·N8-2)·의도적 제외 3.

**검증**: api jest 48개 파일 530건 통과(`permission-admin`에 적용 권한 응답 1건 — 역할 기본값·개인 예외 반영, 원본 미노출, 직원 4칸, 본사 없음). admin-web lint·빌드. 화면 자동 테스트 9건 통과(새 1건 — 로그인한 김민수 화면에서 보이던 "+ 회원 등록"·"CSV 내려받기"·업무지원 요청 메뉴가 본사 변경 + focus 뒤 사라지고, 회원 목록 조회와 "+ 글쓰기"는 남는다). 숨김 조건을 넣은 나머지 버튼(프로그램·시설·자산·강사·예약·근태·직원)은 lint·빌드(타입체크)만 — **화면 동작은 검증되지 않음**.

**작업 중 실수**: 관리자 웹에 Prettier를 설정 없이 돌려 57개 파일 서식이 통째로 바뀌었다(관리자 웹에는 Prettier 설정이 없고 저장소 서식은 기본값과 다르다). 커밋 전에 `git checkout`으로 되돌리고 수정만 다시 적용했다 — 관리자 웹에는 서식 도구를 돌리지 않는다.
