# 진행 로그 — 인덱스

> **상태**: 진행 중. 이 문서는 "무엇을 만들었나"가 아니라 **"왜 이렇게 일하게 됐고, 무엇을 근거로 정했으며, 어떻게 검증했는가"**를 시간 순서로 남긴다.
> ADR([domains/*.md](../domains))이 "이 결정 하나"를 기록한다면, 이 문서는 **결정들 사이의 인과관계와 이 프로젝트의 작업 방식 자체가 바뀐 지점**을 기록한다. 도메인 사이클을 하나 끝낼 때마다 여기에 한 단락을 추가한다([03_도메인_사이클_템플릿.md](../process/03_도메인_사이클_템플릿.md) §12에 반영).
> **읽는 법**: 각 단락은 "계기 → 한 일 → 근거/수치 → 결과" 순서다. 수치는 출처를 반드시 표시한다(실측/계산/가정).
> **2026-10-01부터 한 건에 파일 하나**(`log/NNN.md`)다. 새 기록은 다음 번호로 새 파일을 만들고 아래 표에 한 줄 추가한다. 세션 시작 때 이 폴더를 읽지 않는다 — 지금 상태는 [STATUS.md](../STATUS.md), 이 폴더는 "왜 그렇게 됐나"를 따라갈 때만 연다.
