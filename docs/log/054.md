# 054. Lambda Function URL을 저장소·로그에서 뺐다 — 공개 저장소라 403 요청도 과금되기 때문 (2026-10-02)

> [진행 로그 인덱스](README.md)

**계기**: CLI-RUNBOOK을 로컬에서 실행하려다 첫 AWS 계정이 "새로운 AWS 경험"(Sign up for AWS (new))이라 AWS 관리 SCP가 프로젝트 리전(시드니) 밖의 Lambda와 `iam:*Provider*`(GitHub OIDC)를 막는 것을 확인했다. 유료 플랜에도 같은 SCP가 있고, 풀려면 되돌릴 수 없는 "고급 기능 활성화"가 필요하다. 사용자가 그 계정의 관리 계정을 해지하고 클래식 계정으로 가기로 했다. 다만 이전 가입 이력 때문에 Free plan을 쓸 수 없어서 **비용 위험을 우선 검토**했다. 정상 사용은 Always Free 범위 안이다(추정). 반면 런북대로 하면 Function URL이 공개 저장소(`wrangler.jsonc` `vars`)와 Actions 로그(`vars.LAMBDA_FUNCTION_URL`)에 남는다. 앱이 403으로 거절해도 Lambda 호출로 과금되므로, 수집된 주소가 곧 비용 위험이다.

**한 일**:
- `cloudflare-worker/wrangler.jsonc`: `vars.API_ORIGIN`(Render 주소)을 지우고 `secrets.required: ["API_ORIGIN"]`을 넣었다. origin 주소는 Worker secret으로만 둔다. secret이 없으면 `wrangler deploy`가 실패해서, origin 없이 배포되지 않는다. Worker 코드는 `env.API_ORIGIN`을 그대로 읽어 변경이 없다.
- `.github/workflows/deploy-api-lambda.yml`: health 확인 URL을 `vars.LAMBDA_FUNCTION_URL` → `secrets.LAMBDA_FUNCTION_URL`로 바꿨다. Secret은 로그에서 가려진다.
- `aws-lambda/README.md` 4·5번, `CLI-RUNBOOK.md` 4·5번, `cloudflare-worker/README.md`: 등록과 전환을 `wrangler deploy --secrets-file`로 바꿨다. 코드와 secret을 한 번에 올려 origin이 비는 순간이 없다. Function URL을 문서에 적지 않는다는 규칙도 넣었다.

**근거**: [D37](../decisions/D37.md)(Worker의 `API_ORIGIN`만 Function URL로 바꾼다 — 의도는 그대로, 값을 두는 곳만 바뀐다). 대안은 "노출 감수 + 비용 안전장치에만 의존"이었고, 수정 비용이 작아서 사용자가 이 방식을 골랐다. `secrets.required`·`--secrets-file`은 Cloudflare 문서(2026-03 changelog) 기준이고, 로컬 wrangler는 4.142.0이다.

**검증**: `wrangler deploy --dry-run` 통과 — `secrets` 설정이 받아들여지고 바인딩에서 `API_ORIGIN` 변수가 빠졌다. Worker `tsc --noEmit` 통과, 워크플로 YAML 파싱 통과. **검증되지 않음**: 실제 배포에서 secret 누락 시 실패하는지, 기존 배포의 일반 변수 `API_ORIGIN`과 secret 이름이 충돌하는지(README에 대처를 적어 둠), 워크플로 실동작(AWS 계정 미준비). doc-check 통과(355개 파일).

**곁가지**: `scripts/doc-check.mjs`가 Windows에서 `new URL(import.meta.url).pathname`(`/C:/...`) 때문에 `chdir`에 실패했고, 커밋 전 hook이 이번 커밋을 막았다. `fileURLToPath`로 고쳐 별도 커밋으로 넣었다(사용자 승인). Linux CI 동작은 같다.

**커밋**: (1) doc-check Windows 경로 수정 (2) wrangler.jsonc, deploy-api-lambda.yml, aws-lambda/README.md·CLI-RUNBOOK.md, cloudflare-worker/README.md, STATUS, 이 로그.
