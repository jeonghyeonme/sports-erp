# 221. branch-isolation 테스트가 날짜가 지나며 깨짐 — 휴가 신청 픽스처를 오늘 기준 날짜로 (2026-11-12)

> [진행 로그 인덱스](README.md)

**계기**: 문서만 바꾼 PR #154의 CI에서 api 테스트가 실패했다(2026-11-12). 로컬에서 재현하니 `branch-isolation.spec.ts` 114건이 모두 `beforeAll` 픽스처에서 실패 — 휴가 신청이 409 `LEAVE_REQUEST_OVERLAP`.

**원인**: 픽스처가 휴가 날짜를 `2026-12-01~12-02`로 박아 두었다. 이 파일은 고밀도 템플릿(D58 시연 데이터 층)을 쓰는데, 시연 데이터는 실행일 기준 "앞으로 3주"까지 직원 휴가를 만든다. 11/12부터 그 범위가 12/02에 닿아 같은 직원의 휴가와 겹쳤다 — PR 내용과 무관하고 날짜가 원인.

**한 일**: 휴가 날짜를 오늘(KST) 기준 약 4달 뒤 첫 월요일·화요일로 계산(`nextMondayAfter(120)`). 고밀도 템플릿을 쓰는 다른 테스트의 고정 날짜도 훑었다 — 지난 날짜(업무일지·취득일·지난 회차), 먼 미래(2098~2099), 거부를 확인하는 공격 요청 본문(회차·근태 정정 `2026-12-01` — 403이 먼저라 날짜와 무관), 날짜로 기대값을 DB에서 세는 목록 테스트라 날이 지나도 깨지지 않는다.

**근거**: D58(고밀도 템플릿은 시드 개수·날짜를 박지 않는다), apps/api/CLAUDE.md 날짜 계산 규칙.

**검증**: 로컬 실DB에서 수정 전 `branch-isolation` 114건 실패 재현 → 수정 후 114건 통과. 전체 jest는 커밋 전 hook·CI.
