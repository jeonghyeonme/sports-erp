# 184. pack-midterm.mjs — Windows 경로 깨짐 수정, docs/deliverables 안의 제출 폴더 허용 (2026-10-25)

> [진행 로그 인덱스](README.md)

**계기**: 사용자 PC(Windows)에서 `--outputs-only`(log/183)가 "docs/deliverables에 없음: RFP이행증빙.pdf"로 멈췄다. 파일은 있었다.

**원인**: 저장소 루트를 `new URL('../..', import.meta.url).pathname`으로 구했다 — Windows에서는 `/C:/Users/…`가 되어 `join` 결과가 존재하지 않는 경로가 된다. 리눅스에서만 시험해 놓쳤다(log/179부터 있던 결함).

**한 일**:
- 루트를 `fileURLToPath`로 구한다.
- 사용자는 제출 폴더를 `docs/deliverables/midterm-submission`에 두었다 — "목록에 없는 산출물" 검사가 폴더는 보지 않게(파일만), `.gitignore`에 `/docs/deliverables/midterm-submission/` 추가.
- 같은 `.pathname` 패턴이 `capture-rfp.mjs`·`capture-manual.mjs`·`license-report.mjs`에도 있다 — 이번에 돌린 스크립트가 아니라 고치지 않았다(Windows에서 돌리면 같은 문제).

**검증**: 사용자 배치를 재현(`docs/deliverables/midterm-submission` 안에 01~04, 01·03 PDF 채움)해 `--outputs-only` 실행 → 01·03 그대로, 04만 6개 폴더. `fileURLToPath('file:///C:/Users/…/', {windows:true})`가 `C:\Users\…\`인 것 확인. 사용자 PC 실행은 사용자 확인 대기 — 검증되지 않음.
