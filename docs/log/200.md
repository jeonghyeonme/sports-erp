# 200. 회원 찾기 줄이기 — 상단 바 회원 빠른 찾기와 회원 상세 탭 주소화·PT 먼저(D72), PT 세션 차감 6→3 (2026-11-08)

> [진행 로그 인덱스](README.md)

**계기**: log/199의 회원 찾기 대안 A~D 중 사용자가 B+C를 골랐다(D72).

**한 일**
- **상단 바 회원 빠른 찾기**(`components/MemberQuickSearch.tsx`, `layout/AppLayout.tsx`): 본사·지점 관리자 중 `member` 조회 권한이 있는 사람에게만 그린다. 2자 이상 치면 0.3초 뒤 `GET /members?q=&limit=5`로 최대 5건, 고르면 회원 상세. 키보드 ↑↓·Enter·Esc, combobox/listbox 역할. 6건 이상이면 "회원 목록에서 모두 보기" → `/members?q=`(회원 화면이 주소의 검색어를 받도록 고침 — 이미 그 화면이면 렌더 중 이전 값 비교, admin-web CLAUDE.md 패턴 1). 새 API 없음.
- **회원 상세 탭을 주소에**(`pages/MemberDetailPage.tsx`): `?tab=enrollments|pt|payments`, 없으면 `ptRemainingTotal` > 0일 때 PT 탭, 아니면 수강내역. 탭을 바꾸면 주소를 replace로 바꾼다.
- 화면 도움말(`lib/help-content.ts`) 회원·회원 상세 문구, 디자인시스템 §5에 "상단 바 회원 빠른 찾기" 절.
- 화면 자동 테스트 1건 추가(`e2e/tests/admin-branch.spec.ts`): 시설 화면에서 빠른 찾기 → 다른 지점 회원(강남 오영희)은 결과 없음 → 서초 이수진 고르면 상세, 남은 PT가 있어 PT 탭 먼저("세션 사용" 보임), 수강내역을 누르면 주소가 `?tab=enrollments`. 측정 스크립트 B02~B04를 빠른 찾기로 바꿨다.
