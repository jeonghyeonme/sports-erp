# 058. 종합 발표 덱을 만들었다 — 다섯 요소 + 4주차 이후 진행 내역, 라이브 데모 없음 (2026-10-05)

> [진행 로그 인덱스](README.md)

**계기**: 사용자가 Proposal·요구사항·데이터·설계 Diagram·개발환경/기술스택(AI 포함) 다섯 요소를 담은 발표자료를 요청했다. 마무리는 4주차 발표 이후 커밋만으로 진행 내역을 보여주고, 회원 앱 보류 이유를 명시하기로 했다. 라이브 데모 없이 Slides 아티팩트로 만든다.

**한 일**: [4-5 구성안](../presentation/4-5_종합발표_슬라이드구성.md)과 생성 소스(`presentation/assets/4-5_종합발표/deck-source/`)를 만들고 덱 40장을 게시했다. 청중의 질문 하나에 파트 하나로 답하고, 파트 끝 문장이 다음 파트의 질문이 되도록 짰다. 도식 7개(사업 순환, 회원 앱 요청량, 핵심 엔티티, 구성도, 격리 흐름, 예약 흐름, 방법론 순환)는 4주차 `lib.js`로 그렸다.

**근거**: 숫자는 코드·git에서 다시 셌다(기준 `2665ed8`, 주간 범위 `c20306d..8c953ec`). 회원 앱 요청량은 계산값이라 슬라이드·노트에 "실측 아님"을 적었다([057](057.md)). Lambda는 "첫 배포·헬스체크까지"로만 썼다([056](056.md)).

**검증**: 생성기 린트(24px·SVG·요소 수·노트 길이) 통과, doc-check 통과. 게시한 덱의 렌더 결과(겹침·잘림)는 **확인하지 않았다** — 발표자가 덱을 열어 확인해야 한다. 캡처는 새로 찍지 않고 3주차 캡처 2장을 재사용했다.
