스포이즘 ERP 개발 작업계획서

과업 스포이즘 기업성장을 위한 ERP 시스템 개발 수행 방식 1인 개발, 기능 단위로 세로 완성 구성 시스템 구조 → 개발 단계 → Phase별 상세 근거 내부 공통설계서(아키텍처·ERD·로드맵)

적용 원칙 — 8개 기능 + 확장 범위를 날짜로 쪼개기보다, 기능 단위로 묶어 "이 정도 범위가 끝나면 이런 데모가 나온다"는 완성 단계만 정의한다. 실제 작업 순서는 기능 간을 오가며 유동적으로 진행된다.

이 문서는 일정표 역할과 함께, 시스템이 어떤 구조로 짜여 있는지(아키텍처·폴더·권한·도메인)를 한 장에서 훑어볼 수 있는 개요 역할도 겸한다.
