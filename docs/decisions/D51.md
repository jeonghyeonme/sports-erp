# D51. 남은 일은 RFP 문구를 기준으로 채운다 — "페이지 위치"는 경로 표시로, 지점은 98곳으로 되돌리지 않고 5곳 고밀도 + 규모 설계 유지 (2026-10-14)

> 결정 기록 [인덱스](README.md) · 경위는 [log/112](../log/112.md) · [D40](D40.md)(범위 재설정)·[D41](D41.md)(회원 웹) 위에 얹는다. 지점 범위는 D40을 바꾸지 않고, 시연 데이터 방향(log/106)을 확정한다

**컨텍스트(Driver)**:
- 발표에서 "RFP대로 하라"는 지적을 받았다(사용자, 2026-10-14). 원문을 다시 대조하니 기능 표는 대부분 덮었지만, RFP 문구와 달리 우리가 범위를 바꾼 곳(앱 → 모바일 웹, 98 → 83곳, 세부 권한 → 역할 4개)과 미구현(업무지원 요청, 업무일지 열람 화면, 달력형 예약 등)이 남아 있다. RFP Ⅴ-7은 "사전에 협의되지 않은 사항은 인정되지 않는다"고 적는다.
- UI/UX 요구 "페이지 위치 정보를 MAP형태로 표시"를 요구사항추적표는 지도(외부 지도 API)로 읽고 미구현으로 두었다. 같은 칸의 다른 항목은 모두 화면 구성(통일된 UI·권한별 버튼·입력창 크기·달력형 예약)이고 문구도 "페이지 위치"다.

## 결정

1. **남은 작업의 우선순위는 "RFP 문구 회복"이다.** 비용이 작은 것부터 채운다(log/112의 1번 묶음: 경로 표시, 업무일지 관리자 열람, 회원 웹 이용 안내, 개인정보처리방침). 중간 규모(업무지원 요청·달력형 예약·종목/시간대/연령대 필터·첨부·인사 변경 신청)와 "앱" 요구(하이브리드 앱), 세부 권한, 산출물 보강은 각각 따로 정한다.
2. **"페이지 위치 정보를 MAP형태로 표시" = 현재 화면의 경로 표시(breadcrumb)로 해석한다**(사용자 결정). 관리자 웹 모든 화면 위에 `홈 › 메뉴 그룹 › 화면 › 상세`를 주소에서 만들어 보인다. 산출물·발표에서는 이 해석을 명시한다.
3. **지점은 98곳으로 되돌리지 않는다**(사용자 결정). 시연 데이터는 계약 상태별 지점 5곳(정상 2·갱신 임박·만료·종료)에 실제 같은 밀도의 이력을 넣는 방향(log/106)을 유지하고, 코드와 설계 숫자는 지점 수가 늘어나는 것을 전제로 만든다(목록 페이지네이션 D43, 요청량 산정 design-constants ⑬, 동시 실행 상한 D37·D50). 98곳은 "운영 규모 산정의 기준"으로 남는다.

## 대안 → 트레이드오프

| 대안 | 얻는 것 | 비용·위험 | 판단 |
|---|---|---|---|
| **경로 표시(선택)** | 작은 화면 작업으로 RFP 한 줄을 채움, 화면 위치를 늘 보여 줌 | 해석이 우리 판단 — 문서에 명시해야 함 | 선택 |
| 지도 API로 지점 위치 표시 | 다른 해석도 덮음 | 외부 API 키·비용, 문구("페이지 위치")와 덜 맞음 | 기각 |
| 사이트맵 화면 | 전체 구조를 한 장에 | 화면 하나 더, 매 화면에서 위치는 안 보임 | 보류 |
| 98곳 시드 복원 | RFP 숫자와 일치 | 대부분 이력 없는 빈 지점 — 시연 밀도가 떨어지고, D40의 무료 한도 논리와 섞인다 | 기각(사용자) |
| **5곳 고밀도 + 규모 설계(선택)** | 지점마다 실제 같은 시나리오 시연, 규모는 숫자·구조로 보임 | "98곳"을 데이터로 직접 보이지 못함 — 산정·발표에서 설명 | 선택 |

## 결과

- 좋아지는 것: 지적받은 "RFP와 다르다"를 항목별로 줄여 간다. 해석이 갈리는 항목은 결정 기록으로 근거가 남는다.
- 감수하는 것: "앱"·세부 권한·98곳은 여전히 RFP 문구와 다르다 — 각각 결정 근거(D40·D1·이 문서)로 설명한다.
- 개인정보처리방침은 시연용 초안이다. 가입 화면의 개인정보 수집·이용 동의는 화면에서만 받고 동의 시각은 저장하지 않는다(저장하려면 스키마 변경 — 승인 대상).

**재고 트리거**: 발주처(또는 평가자)가 "페이지 위치"를 지도로 요구할 때 → 지점 지도 화면 추가. 실서비스 전환으로 지점 수를 늘릴 때 → 시드 생성기(`branch-generator.ts`)로 규모를 키우고 ⑬·D37 상한을 다시 본다.
