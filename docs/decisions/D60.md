# D60. 세부 권한 — 역할 상한 + 역할 기본값 + 개인 예외 (2026-10-20)

> 결정 기록 [인덱스](README.md) · 경위는 [log/146](../log/146.md) · **[D1](D1.md)(4-Role 고정, 개별 권한 없음)을 대체한다.** 도메인 쪽 기록은 권한관리 ADR-AUTH-07.

**컨텍스트(Driver)**: RFP 1-1 #1 권한관리 "사용자별·프로그램별 권한 설정(입력·수정·삭제·조회·출력)"과 1-2 #7 UI 보안 "그룹별·개인별·기능별 접근 통제"(추적표 F1-2·N7-2)가 부분 충족으로 남았다. D1은 1인 개발 공수 때문에 역할 4개 고정으로 줄였는데, 남은 부분 조항 중 코드로 메울 수 있는 것이 이것뿐이다.

**상위 목표(D53)**: 노하우 습득 — 실무 ERP의 RBAC + 개인 예외(ACL) 구조를 직접 만든다. **핵심 변수**: 기존 불변식(지점 격리·인사 권한 분리)을 깨지 않을 것, 요청당 DB 왕복(D37·D50, W 약 40ms), 새 라우트가 선언을 빠뜨리는 위험. **답안지**: 역할 기본 권한 + 사용자별 허용/차단, 서버 판정, 화면은 숨김만.

## 결정 (사용자 선택 2026-10-20 — "역할 기본값 + 개인 예외", "상한 안에서만", 추천안)

1. **상한 = 코드의 `@Roles`.** 표는 그 안에서만 끄고 켠다. 개인 "허용"은 역할에서 끈 칸을 그 사람에게 되살리는 용도이고 상한을 넘지 못한다 — 서비스 코드의 역할 가정을 바꾸지 않아 격리·인사 불변식이 구조적으로 안전하다.
2. **표가 다루는 범위**: 지점 관리자·직원, 기능 15개 × 동작 5개(조회·입력·수정·삭제·출력, 카탈로그 `src/common/permissions/permission-catalog.ts`). 표 밖: 본사(항상 전부 — 자기 잠금 방지), 회원(본인 화면만), 인사 권한(채용·발령·역할 전환·퇴사·계약 상태 — 인사 권한 분리), 본인 업무(출퇴근·내 휴가·내 업무일지·비밀번호·회원 본인 예약·결제).
3. **판정 순서**: 로그인(ADR-AUTH-01) → 역할 상한(RolesGuard) → 지점 격리(BranchScopeGuard, D46) → 세부 권한(PermissionGuard: 개인 예외 → 역할 기본값 → 허용). 거부는 403 `PERMISSION_DENIED`.
4. **데이터**: `RolePermission(role, feature, action, allowed)` — 상한에서 바꾼 칸만 행(없으면 허용), role은 지점 관리자·직원만(CHECK). `AccountPermission(accountId, feature, action, allowed, grantedBy)` — 개인 예외. `feature`는 문자열(카탈로그 키, 서버 검증), `action`은 enum `PermissionAction`. 변경 이력은 AuditLog `PERMISSION_CHANGED`(action이 문자열 열 — 스키마 변경 없음, 2단계).
5. **성능**: 개인 예외는 매 요청 계정 조회에 실어 읽는다(왕복 증가 없음, 즉시 반영). 역할 기본값은 실행 환경마다 30초 캐시(왕복 증가 없음, 바꾼 값은 최대 30초 늦게 반영 — 같은 실행 환경은 변경 API가 캐시를 비운다).
6. **출력**: CSV는 브라우저가 목록 API로 만든다(D54). 출력 요청은 `?export=true`를 붙이고 서버가 출력 권한을 본다. **한계**: 조회 권한이 있으면 쪽을 넘겨 같은 데이터를 받을 수 있다 — 실제 방어선은 조회 권한이고, 출력 권한은 대량 내려받기 경로를 통제·기록하는 수준이다.
7. **선언 누락 방지**: 지점 관리자·직원이 닿는 라우트는 모두 `@Permission(feature, action)` 또는 이유를 단 `@PermissionExempt`를 가진다. `permission-coverage.spec.ts`가 라우트 표와 카탈로그를 대조한다(쓰이지 않는 상한 칸도 실패).
8. **순서**: ① 스키마·카탈로그·가드·선언·테스트(log/146) ② 권한 관리 화면(역할 기본값 표·개인 권한)과 변경 API·변경 이력 ③ 관리자 웹이 권한대로 메뉴·버튼 숨김, 화면 자동 테스트, 추적표.
