# D54. 목록 출력은 CSV, 화면에 보이는 그대로(전화번호 마스킹 유지), 역할 기준 (2026-10-16)

> 결정 기록 [인덱스](README.md) · 경위는 [log/120](../log/120.md) · RFP 1-1 #1 권한관리 "출력"(D51 M6). 세부 권한 표(입력·수정·삭제·조회·출력)는 따로 다룬다([D1](D1.md) 보강, STATUS 2(c))

**컨텍스트(Driver)**: 관리자 웹 어느 목록에도 내보내기·인쇄가 없었다. 회원 목록에는 전화번호가 있다 — 원문을 파일로 내보내면 열람 기록(D47)도 없이 대량으로 빠져나가는 경로가 된다.

**상위 목표(D53)**: 노하우 습득 — 개인정보가 섞인 출력 기능을 실무에서 어떻게 안전하게 다루는지 익힌다. **핵심 변수**: 개인정보(ADR-MEM-04 목록 마스킹·D47 열람 기록), 대량 행(쪽 단위 목록 D43). **답안지**: 관리자 툴은 대개 "CSV(엑셀용 BOM) + 화면에 보이는 그대로".

## 결정 (사용자 선택 2026-10-16, 사용자 설명: 없음 — 추천안 선택)

1. **회원·근태 요약·결제** 목록에 "CSV 내려받기"를 둔다. 열은 화면 표와 같다(`apps/admin-web/src/lib/export-columns.ts`).
2. **브라우저에서 만든다** — 화면과 같은 목록 API를 쓰므로 API 변경이 없고, 전화번호는 목록 API가 준 **마스킹 값 그대로** 나간다. 원문 출력은 만들지 않는다.
3. 쪽 단위 목록은 지금 조건(지점·상태·검색) 그대로 **모든 쪽**을 100건씩 모은다. 한 번에 최대 5,000행, 넘으면 잘렸다고 알리고 조건을 좁히게 한다.
4. 엑셀이 한글을 읽도록 UTF-8 BOM, 글자 셀 맨 앞의 `= + - @`에는 `'`를 붙여 수식 주입을 막는다. 파일 이름은 영문(`members_YYYY-MM-DD.csv` 등) — 한글 이름은 헤드리스 Chromium에서 `download`로 바뀌는 것을 실측했다.
5. **권한은 역할 기준** — 그 목록을 볼 수 있는 역할(본사·지점 관리자)에게 버튼이 보인다. "출력" 권한을 따로 떼는 것은 세부 권한 작업에서 정한다.

## 대안 → 트레이드오프

| 대안 | 얻는 것 | 비용·위험 | 판단 |
|---|---|---|---|
| **CSV 3개 목록, 마스킹 유지(선택)** | API 변경 없음, 원문 유출 경로 없음 | 연락처가 필요한 업무(문자 발송 등)에는 못 쓴다 | 선택 |
| 같은 3개 + 인쇄용 화면(print CSS) | RFP "출력"을 종이로도 덮음 | 화면마다 인쇄 레이아웃 작업 | 보류(요청 시) |
| 서버에서 파일 생성 | 큰 목록도 한 번에 | API·권한 검사·열람 기록 설계가 새로 필요 | 기각 |

**재고 트리거**: 연락처 원문이 담긴 출력을 요구받을 때(→ 사유 입력 + 열람 기록 D47 확장 먼저), 한 번에 5,000행을 넘게 받아야 할 때, 세부 권한 표를 만들 때.
