# D74. 목록·확인 창 일관화 1차 — 화면 전체 로드 목록은 머리글 정렬, 검색은 치는 대로, 확인은 확인 창(dialog), 모달 접근성 (2026-11-08)

> 결정 기록 [인덱스](README.md) · 경위는 [log/202](../log/2026-W45.md#202) · 조사는 [log/197](../log/2026-W45.md#197) A-1~A-4·B-1·B-3

**컨텍스트**: 전수조사(log/197)에서 목록 화면마다 쪽 나누기·검색·정렬·CSV가 제각각이었다 — 머리글 정렬 0곳(디자인시스템 §3 원칙 미적용), 회원 목록만 "검색" 버튼, 브라우저 `window.confirm` 3곳, 관리자 웹 `Modal`에 `role="dialog"` 없음. D67 ① 사용감 확보.

**목록의 두 종류(지금 코드 기준, 이 결정의 전제)**
- **서버 쪽 나누기(D43, 20건 · `Pager`)**: 회원·예약·결제·자산·업무지원·게시판·변경 이력 — 데이터가 시간에 따라 쌓인다. 순서는 서버가 정한다(대부분 최근 것부터).
- **화면 전체 로드**: 직원·프로그램·강사·시설·문서·계약 보존 — 지점 수에 비례해 상한이 있는 목록(문서는 예외로 쌓인다 — D69 2차 때 서버 쪽 나누기로 옮길 후보).

**검토한 대안(정렬)**: (a) 모든 목록 서버 정렬 — 목록 API 7개에 정렬 인자·검증·테스트가 필요하다. (b) 모든 목록 화면 정렬 — 서버 쪽 나누기 목록에서는 지금 쪽 20건만 정렬돼 전체 순서처럼 보이는 오해를 낳는다. (c) **화면 전체 로드 목록만 화면 정렬(채택, 1차)**, 서버 목록은 2차에서 사용자 선택.

**결정(1차 — 화면만, API·권한 변경 없음)**
1. **머리글 정렬**: 화면 전체 로드 표(직원·프로그램·강사·문서)는 머리글을 눌러 정렬한다 — 오름 → 내림 → 해제(처음 순서), 빈 값은 늘 뒤, 글자는 한국어 순서·숫자 인식. 지점별로 묶인 화면은 정렬이 화면에 하나라 모든 묶음이 같은 순서. 머리글은 버튼(키보드)이고 `th scope="col"` + `aria-sort`. 부품 `components/SortTh.tsx`, 로직 `lib/table-sort.ts`. 가려진 값(연락처)은 정렬하지 않는다. 계약 보존 표는 짧고 이미 보존 끝 순이라 넣지 않았다.
2. **검색은 치는 대로**: 회원 목록의 "검색" 버튼을 없애고 0.3초 뒤 서버 검색(Enter는 바로) — 다른 목록의 화면 검색·상단 빠른 찾기(D72)와 같은 동작.
3. **확인 창**: `window.confirm`을 쓰지 않는다 — `components/ConfirmModal.tsx`(취소 + 실행 버튼, 되돌릴 수 없으면 빨간 테두리 버튼). 시설 운영 중단·계약 파일 실물 이관·보존 끝난 파일 정리 3곳을 바꿨다.
4. **모달 접근성**: `Modal`에 `role="dialog"`·`aria-modal`·제목 연결, 열리면 첫 입력 칸(없으면 모달)으로 초점, Esc로 닫기, 닫히면 연 버튼으로 초점을 돌려준다.

**2차 — 사용자 선택이 필요한 것(구현하지 않음)**
- **CSV 확대**: 지금 출력(EXPORT) 권한은 회원·결제·근태만 있다(권한 카탈로그 D60). 직원·자산·문서·프로그램 등에 CSV를 붙이려면 카탈로그에 EXPORT를 더하고 목록 API에 `exportable`을 다는 권한 설계 변경이다.
- **서버 목록 정렬**: 회원(이름·가입일)·자산 등 서버 쪽 나누기 목록의 정렬 — API별 정렬 인자 추가.
- **검색이 없는 목록**: 예약(회원 이름)·자산·업무지원·변경 이력 — 서버 검색 인자 추가.
- **문서 목록 서버 쪽 나누기**: D69 2차(파일 업로드)와 함께.

**결과**: 좋아진 것 — 같은 동작이 화면마다 같은 모양(정렬 머리글·검색·확인 창), 보조기기가 모달·정렬 상태를 읽는다. 감수하는 것 — 서버 쪽 나누기 목록은 아직 정렬이 없어 "어떤 목록은 정렬되고 어떤 목록은 안 되는" 차이가 남는다(머리글 모양으로 구분된다).

**재고 트리거**: 화면 전체 로드 목록이 수백 행을 넘을 때(서버 쪽 나누기로), 2차 항목을 고를 때.
