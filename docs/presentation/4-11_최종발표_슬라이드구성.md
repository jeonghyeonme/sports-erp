# 4-11. 최종 발표(15주차) — 슬라이드 구성안 (덱 1차본, 2026-11-28)

> [4-0 공통지침](4-0_발표자료_공통지침.md)을 따른다. **덱 1차본 게시**(12장, log/252) — 아래 15장 초안 중 7·13·14장은 사용자가 일단 뺐다(2026-11-28). 덱은 [deck-source](assets/4-11_최종발표/deck-source/README.md)에서 생성하고, 조정하면서 이 문서를 고친다. 주간 발표(이번 주에 한 일)가 아니라 **프로젝트 전체를 처음 보는 사람에게** 설명하는 발표다.

## 발표 조건

- 20분(11팀 발표, 평소와 같음) — 슬라이드 약 10분 + **시연 7분** + 여유 3분.
- 강의실 컴퓨터 한 대(사용자, 2026-11-26). 휴대폰 실물 없음 — 회원 웹은 좁은 브라우저 창으로.
- 다음 주 최종 발표, 그다음 주 완성 작업물 제출.

## 서사

아파트·오피스텔 커뮤니티 시설 위탁운영사의 **계약 → 운영 → 운영 기록 → 다시 계약**으로 도는 사업 구조를 한 시스템으로 묶었다. 지점 데이터 격리와 계약 상태가 그 구조를 지키고, 자동 테스트·운영 부하 측정이 그것을 보증한다. 시연에서 그 순환을 한 바퀴 돈다.

## 슬라이드 목록 (초안 15장 → 덱 12장, 7·13·14 일단 제외)

| 3 | `rfp-core` | RFP가 요구한 핵심 둘 | ① 지점 관리자는 자기 지점만(격리) ② 시스템 불안정 → 민원 → 계약 해지(안정성 = 본사 매출). "그래서 이 두 가지를 구조로 지켰다" |

**시간**: 덱 순서로 1~7장(표지~부하) 약 7분 → 8장 `demo`에서 시연 7분 → 9~12장(RFP·진행률·산출물·마무리) 약 2분. 뺀 3장 몫(약 2분)은 여유·질문으로.

**뺀 것(질문 때)**: 인사(채용·파견)·근태·자산·문서함·권한 매트릭스 화면 — 시연 중 메뉴를 한 바퀴 훑어 "있다"만 보인다. 주간 진행 경위·로그 번호.

## 시연 흐름 (7분)

**창 배치(발표 시작 전에 열어 두고, 시연 중 새로고침하지 않는다)**

| 창 | 주소 · 계정 | 놓을 곳 |
|---|---|---|
| A 크롬 일반 창 | 관리자 웹 · 정하늘(본사) — 로그인 화면 데모 계정 버튼 | 화면 왼쪽 2/3 |
| B 크롬 시크릿 창 | 관리자 웹 · 김민수(서초점 지점 관리자) | 화면 왼쪽 2/3(A와 번갈아) |
| C 다른 브라우저(엣지) | 회원 웹 `/m/` · 이수진(회원) — 데모 계정 버튼 | 화면 오른쪽 1/3, 좁은 세로 창 |

관리자 웹은 로그인을 탭 메모리에만 들고 있어 새로고침·같은 탭 계정 전환에 풀린다 — 창을 역할마다 나눈다. 회원 웹은 다른 브라우저로 둬 관리자 창과 섞이지 않게 한다.

| 단계 | 창 · 계정 | 누를 것 | 말할 것 | 시간 |
|---|---|---|---|---|
| **1. 계약 현장 한눈에** | A 본사 | 대시보드 — 계약 상태 카드(정상·갱신 임박·만료·종료) → 운영 실적 차트 | "지점은 아파트와 맺은 계약 현장입니다. 상태마다 할 수 있는 일이 다릅니다" | 1분 |
| **2. 회원이 예약한다** | C 회원 | 홈(혼잡도·내 PT) → 예약하기 → 서초점 강습 → **오늘 회차** → 결제 확인 시트 → 내 예약 | "현장 이용자는 앱으로 예약하고 결제합니다" | 1분 30초 |
| **3. 지점이 바로 받는다** | B 지점 | 상단 처리 대기 → 예약 관리(기본이 오늘) → 방금 예약한 이수진 **체크인** → 시설·혼잡도에서 현장 인원 입력 | "회원이 한 일이 지점 화면에 바로 이어집니다" — A와 C를 나란히 | 1분 30초 |
| **4. 지점은 자기 지점만** | B 지점 → A 본사 | B 상단 회원 찾기에 "오영희"(강남점 회원) → "일치하는 회원이 없습니다" → A에서 같은 검색 → 나옴 | "지점 관리자는 자기 지점 데이터만 봅니다 — RFP 핵심 요구" | 40초 |
| **5. 운영 기록이 계약으로** | A 본사 | 지점 목록 → 마포점(갱신 임박) → 계약 회차 → **갱신 리포트** | "운영 기록이 다시 계약 갱신 협상 근거가 됩니다 — 순환이 닫힙니다" | 1분 30초 |
| (시간 남으면) **6. 계약 종료** | A 본사 | 노원점(종료) 상세 — 갱신·파일 올리기 막힘, 직원 채용 지점 목록에 노원점 없음 | "계약이 끝난 현장은 새 활동이 막히고 과거 기록만 남습니다" | 30초 |

**선택 장면**: 3단계 뒤 C 회원 홈의 혼잡도 카드를 새로고침해 방금 입력한 현장 인원이 반영된 것을 보인다(홈 혼잡도는 60초 캐시·30초 새로고침 간격이 있어 바로 안 바뀔 수 있다 — 리허설로 확인).
