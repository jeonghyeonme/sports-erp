## 5. Q&A 대비

- **Lambda로 운영 전환 완료**: Worker 경유 로그인·데이터 조회까지 확인(사용자, log/059). 배포 헬스체크는 DB를 거치지 않는다. Lambda 위 부하 실측(k6)은 아직이다.
- **19.6만/일·200 rps는 계산값이다.** 세션당 요청 10건은 약한 가정(design-constants ⑩). Lambda 위 k6 실측은 없다 — `loadtest/k6-lambda.js`와 통과 기준(D37 §4)만 준비.
- **회원 앱 보류 이유**: 무료 한도 초과 → 유료 전환·인프라 추가 구성이 필요해 범위가 과하게 넓어진다(log/057, D37 §5).
- **검증 범위**: API는 jest(불변식 3개 + 실DB 동시성, 테스트 파일 27개). 관리자 웹은 테스트 없음(lint·빌드만).
- **채용·재배치**는 API로 구현, 화면은 후속 과제. **PG 어댑터**(ADR-RSV-03)는 미구현.
- **기업 분석**은 RFP와 일반 실무 조사로 재구성한 것이지 스포이즘 내부 자료가 아니다.
