부분 3 · 제외 3

해당 없음 8

발주기관 승인·납품 계약·하자보수·대면 교육처럼 이 프로젝트에 대상이 없는 조항

영역별 조항 수(요구사항추적표 §3, 2026-10-23). 기능·성능은 판정 대상 28개가 모두 완료 또는 조정이다. 시스템~제약의 부분 2개는 결제의 금융기관 연계 확인(테스트 키 실제 호출 전)과 개인정보 업무위탁 계약서 — 둘 다 실운영이 있어야 끝난다. 과업의 부분 1개는 발주기관 검수·도입·기대효과 분석. 제외 3개는 유사기업 분석 둘과 도입 후 기대효과 분석 — 접근할 자료가 없고, 실데이터 없이 숫자를 지어내지 않으려고 뺐다. 해당 없음 8개는 발주기관·납품 계약·대면 교육처럼 대상이 없는 조항.
