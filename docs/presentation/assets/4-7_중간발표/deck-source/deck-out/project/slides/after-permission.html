교육 자료

게시글 서식·이미지, 위험한 내용은 두 겹으로 거른다

세부 권한(D60, RFP F1-2·N7-2): 서버 판정 → 관리 화면·변경 이력 → 관리자 웹 메뉴·버튼·CSV 숨김의 3단계로 만들었다. 처리 대기함(D61): 대시보드 첫 카드에 역할별 "지금 처리할 일" 건수(휴가 승인·인사 변경 신청·결근 확정·업무지원 요청·갱신 임박 지점 등), 메뉴와 상단 배지. 시설별 공지(RFP F4-3, ADR-BRD-05): 지점 공지에 대상 시설을 지정하고 회원 앱이 시설로 거른다. 서식 편집기(D62): 게시글 작성·수정 화면, 서버 허용 목록 정화 + 두 웹의 정화로 두 겹.
