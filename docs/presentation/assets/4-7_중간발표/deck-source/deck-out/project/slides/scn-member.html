회원 모바일 웹(/m/) · 로컬 실행 화면 — 회원은 관리자 웹에 로그인할 수 없다

회원(이수진, 서초점)은 휴대폰 웹 앱(홈 화면에 설치 가능)을 쓴다. 관리자 웹에는 회원이 로그인할 수 없다(D66). ① 등록 지점의 프로그램 회차를 날짜 띠에서 고른다(종목·시간대·연령대 필터). ② 유료 회차는 결제해야 확정된다 — 실제 카드가 아닌 모의 결제(승인 번호 MOCK-…), 시작 24시간 전까지 취소하면 전액 환불. ③ 홈의 혼잡도는 "약 N명/정원 · 강습 a + 현장 b" — 진행 중 강습의 예약 인원은 바로 더해지고, 예약 없이 온 인원은 지점 직원이 입력한다(ADR-FAC-05). 30분 넘게 입력이 없으면 경고. ④ 공지는 다니는 지점·시설 것만 보인다.
