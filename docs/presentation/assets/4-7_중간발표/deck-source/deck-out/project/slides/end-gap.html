T3-2 개발 → 테스트 → 검수 → 도입 → 기대효과 분석 — 개발·테스트·운영 배포까지. 실운영을 하지 않기로 해(D67) 범위 밖으로 둔다. 제외 3: T2-1 유사 기업체 관리 시스템 분석, P2-3 유사기업 직원 매뉴얼 분석(벤치마킹 대상 접근 불가), P2-2 도입 후 기대효과 분석(실제 매출·계약 데이터 없이 숫자를 만들면 근거 없는 추정). 해당 없음 8: 도입 승인·작업계획서 승인·발주기관 검증·기술지원 확약·무상 보증·업그레이드·결제내역 처리(원문 미확정)·대면 교육.
