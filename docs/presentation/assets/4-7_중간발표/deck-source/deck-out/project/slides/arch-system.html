서버는 요청마다 따로 실행되고 동시 10개를 넘으면 바로 거절합니다 — 몰려도 느려지며 무너지지 않게

브라우저(관리자 웹·회원 웹) → 엣지(Cloudflare Worker: 화면 파일 제공, /api 요청 전달, 로그인 요청 제한) → 서버(AWS Lambda 서울: 요청마다 따로 실행, 동시 실행 상한 10, 넘치면 바로 503 안내) → DB(Supabase PostgreSQL 서울). 화면과 API를 한 주소로 묶어 교차 출처 문제를 없앴다. 지점 검사·권한 판정은 서버 길목 한 곳(D46·D60). 첫 배포(Render 공유 CPU)에서 동시 로그인 40명에 15초가 걸린 것을 측정해 실DB 전환과 Lambda 이관을 결정했다(D24·D26·D37). 배포는 dev 브랜치 push 때 자동(헬스체크 실패 시 이전 버전으로 되돌림).
