Ⅳ. RFP 이행 · 기능 (3/4)

기능 22조항 — 완료 19 · 조정 2 · 해당 없음 1

RFP p.5 기능 1~8

조항

RFP가 요구한 것(원문 요약)

구현한 것

상태

회원관리

F5-1

회원 인적사항·수강내역·예약및결제내역·PT 잔여 세션 기록

회원 한 명의 인적사항·수강·예약·결제·PT 남은 횟수를 한 화면에서 본다.

완료

F5-2

현장 관리자는 해당 현장 회원 정보만(타현장 조회 불가)

지점 관리자는 자기 지점 회원만 보고, 다른 지점 회원을 열면 거절된다.

완료

예약및결제

F6-1

무/유료 프로그램 게시 후 프로그램별 예약, 모바일 결제

회원이 휴대폰에서 강습 회차를 예약하고 결제한다. 결제는 실제 카드 대신 모의 결제다.

조정

F6-2

결제내역 처리 방법 추후 논의

원문이 '추후 논의'라 판정하지 않는다. 결제 내역 조회와 내려받기는 있다.

해당 없음

강사,프로그램게시

F7-1

각 현장 종목별 강사·프로그램 정보 게시

지점마다 강사와 프로그램을 등록하고, 회원 앱에 강사 소개와 함께 보인다.

완료

F7-2

종목별·시간대별·연령대별 프로그램 리스트

프로그램을 종목·시간대·연령대로 골라 볼 수 있다(관리자 웹과 회원 앱 모두).

완료

조항별 화면·결정 기록은 함께 낸 RFP 이행 증빙(PDF)의 같은 조항 번호

기능 요구(권한·인사·근태·게시판·회원·예약결제·강사프로그램·혼잡도). 조정 2개: 모바일 결제는 실제 PG 대신 모의 결제(상태 전이·결제/취소 경합은 실물처럼, D5·D6·ADR-RSV-07), 혼잡도 "실시간 또는 30분 이내"는 계측 장비 없이 진행 중 강습 예약 인원 자동 + 현장 인원 직원 입력(ADR-FAC-05). 해당 없음 1개는 원문이 "결제내역 처리 방법 추후 논의"로 미확정인 조항.
