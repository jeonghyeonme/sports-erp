조항

RFP가 요구한 것(원문 요약)

구현한 것

상태

UI/UX

N6-1

전체 시스템에서 통일성 있는 UI

색·글꼴·간격을 공통 값으로 정해 모든 화면이 같은 모양을 쓴다.

완료

N6-2

이용자 편의 우선의 직관적·간략한 UX

대시보드 첫 칸에 '지금 처리할 일'을 모았고, 역할별로 화면을 점검해 불편 14건을 고쳤다.

완료

N6-3

페이지 위치 정보를 MAP 형태로 표시

'지도 형태'를 지금 위치를 보여 주는 경로 표시(홈 › 메뉴 › 화면)로 해석해 모든 화면 위에 두었다.

조정

N6-4

권한에 따라 수정·삭제·조회 버튼 기능 제어

권한이 없는 사람에게는 등록·수정·삭제·내려받기 버튼이 보이지 않고, 서버도 한 번 더 막는다.

완료

N6-5

필드 속성에 맞는 입력 언어 우선 적용, 입력창 크기 최적화

전화·숫자·이메일 칸은 휴대폰에서 맞는 자판이 뜨고, 입력 길이와 칸 크기를 맞췄다.

완료

N6-6

예약 관리를 달력·스케줄표 형태로 표시

관리자는 주간 시간표로, 회원은 날짜 띠로 예약을 본다.

완료

UI 보안

N7-1

인사·회원 개인정보가 별도 절차 없이 노출되지 않음

목록의 전화번호는 가운데를 가리고, 원문을 열어 볼 때마다 기록이 남는다.

완료

N7-2

권한에 의한 접근 통제 — 그룹별·개인별·기능별

역할별·사람별·기능별로 접근을 나누고, 지점 단위로도 막는다.

완료

조항별 화면·결정 기록은 함께 낸 RFP 이행 증빙(PDF)의 같은 조항 번호

부분 2개는 실운영이 있어야 끝난다 — 결제의 금융기관 연계 확인(결제 회사를 바꿔 끼우는 구조와 연계 확인 문서까지, 테스트 키 실제 호출 전)과 개인정보보호법 제26조 업무위탁(처리방침의 위탁 고지·절차 문서까지, 위탁 계약서 서명·감독 기록은 실운영 때). 조정 1개: "페이지 위치 정보를 MAP 형태로"를 화면 위 경로 표시로 해석했다(D51). 해당 없음 6개는 발주기관·납품 계약이 없는 조항이라 한 줄로 묶었다.
