Ⅳ. RFP 이행 · 과업·산출물·개념도 (1/3)

과업·산출물·개념도 18조항 — 완료 11 · 조정 2 · 부분 1 · 제외 3 · 해당 없음 1

RFP p.3~4 · p.7 · 개념도 p.4

조항

RFP가 요구한 것(원문 요약)

구현한 것

상태

과업1

T1-1

기업 구조 분석(지점현황·지역분포·근무자 구조·조직도)

지점 현황·지역 분포·근무자 구조·조직을 분석해 기업 분석 문서에 담았다.

완료

T1-2

관리시스템 분석(인적/물적자원·본사와 지점 관리·현장관리·효율성)

인적·물적 자원, 본사·지점 관리, 현장 관리를 분석했다. 물적 자원 관리가 빠져 있던 것을 찾아 채웠다.

완료

과업2

T2-1

유사 기업체 관리 시스템 현황 분석

비교할 회사 자료에 접근할 수 없어 하지 않았다.

제외

T2-2

당사에 적합한 ERP/앱 개발 컨설팅

기업 분석과 제안서에서 위탁운영 회사에 맞는 시스템을 제안했다.

완료

T2-3

탑재할 목표 프로세스·기능 설계

9개 업무 영역마다 설계 문서를 쓰고 아키텍처 설계서로 묶었다.

완료

T2-4

UI/UX 계획 수립 및 스타일 디자인

디자인 시스템 문서로 화면 스타일을 정했다.

완료

과업3

T3-1

요구사항 표를 반영한 프로그래밍

요구사항 표의 기능·성능 조항을 모두 만들었다(위 기능·성능 절).

완료

T3-2

앱 개발 → 테스트 → 검수 → 완료 → 도입 → 경영개선 기대효과 분석

개발·테스트·운영 배포까지 했다. 검수·도입·효과 분석은 실제 운영을 하지 않아 없다.

부분

조항별 화면·결정 기록은 함께 낸 RFP 이행 증빙(PDF)의 같은 조항 번호

제출물 이름까지 적었다. 조정 2개: 산출물1 "ERP 앱 1개"는 관리자 웹 + 회원 모바일 웹(홈 화면 설치)으로(D40·D41·D45), 산출물3 개발 작업계획서는 아키텍처 설계서와 업무 영역별 작업 절차로. 제외 3개는 유사 기업체 시스템 분석·유사기업 매뉴얼 분석(접근 불가)과 도입 후 기대효과 분석(실데이터 없는 수치 예측) — 의도적 제외. 부분 1개는 발주기관 검수·도입·기대효과 분석이 없는 과업3 흐름. 해당 없음 1개는 팀장급 대면 교육.
