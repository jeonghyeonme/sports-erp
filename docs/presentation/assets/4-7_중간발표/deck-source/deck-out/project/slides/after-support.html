본사의 처리 창

강남점 요청 — 처리중·완료·반려와 답변

RFP 개념도(p.4)의 "현장 → 본사 업무지원 요청"은 처음 설계에 없었다. 새 테이블을 만들었다(D56) — 지점 관리자가 분류(시설·인력·기타)와 내용을 올리고, 본사가 처리중 → 완료 또는 반려로 바꾼다. 반려는 답변이 필수(DB 제약). 본사 대시보드 처리 대기함에 처리할 요청 수가 뜬다. 화면은 본사의 처리 창.
