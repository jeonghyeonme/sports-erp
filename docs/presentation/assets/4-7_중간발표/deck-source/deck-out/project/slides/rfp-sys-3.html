조항

RFP가 요구한 것(원문 요약)

구현한 것

상태

UI 보안

N7-3

결제 시스템의 금융·보안기관 연계 가능 여부 확인

결제 회사를 바꿔 끼울 수 있게 만들고 연계 확인 문서를 썼지만, 실제 결제 호출은 하지 않았다.

부분

보안요건

N8-1

인원·문서·장비 보안관리계획 수립

인원·문서·장비·비밀값 보안관리계획을 문서로 세웠다.

완료

N8-2

개인정보보호법 제26조(업무위탁) 준수

개인정보처리방침에 데이터를 맡긴 업체(위탁)를 밝혔다. 위탁계약 서명은 실제 운영 때 할 일이다.

부분

규정의준수

N10-1

산출물의 지식재산권 주의·준수

쓰는 라이브러리 243개의 라이선스를 목록으로 만들고, 모두 자유롭게 쓸 수 있는 종류임을 확인했다.

완료

N10-2

저작권 문제가 없는 저작물 구현

이미지·아이콘은 직접 만들었고 외부 글꼴·이미지 파일을 쓰지 않는다.

완료

시스템도입 · 설치및운영 · 하자보수

N1·N2·N9

도입 승인 · 작업계획서 승인 · 발주기관 검증 · 기술지원 확약 · 무상 보증 · 업그레이드

발주기관·납품 계약이 없어 대상이 없다(6조항). 검증은 자동 검사(코드 검사·테스트·문서 검사)로 대신했다.

해당 없음

조항별 화면·결정 기록은 함께 낸 RFP 이행 증빙(PDF)의 같은 조항 번호

부분 2개는 실운영이 있어야 끝난다 — 결제의 금융기관 연계 확인(결제 회사를 바꿔 끼우는 구조와 연계 확인 문서까지, 테스트 키 실제 호출 전)과 개인정보보호법 제26조 업무위탁(처리방침의 위탁 고지·절차 문서까지, 위탁 계약서 서명·감독 기록은 실운영 때). 조정 1개: "페이지 위치 정보를 MAP 형태로"를 화면 위 경로 표시로 해석했다(D51). 해당 없음 6개는 발주기관·납품 계약이 없는 조항이라 한 줄로 묶었다.
