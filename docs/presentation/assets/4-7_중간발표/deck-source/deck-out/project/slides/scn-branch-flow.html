다른 지점 회원이나 직원은 주소를 알아도 열리지 않습니다 — 서버가 지점마다 막습니다

지점 관리자(김민수, 서초점)의 하루. ① 회원 등록 — 계약 종료 지점이면 막힌다. 회원 번호는 지점별로 자동. ② 프로그램의 강습 회차를 열면 회원 앱에서 예약할 수 있고, 주간 시간표에서 예약 현황을 본다. ③ 직원 출퇴근과 휴가 신청을 승인하고, 빠진 날은 정정·등록한다(변경 이력에 남는다). ④ 처리 대기함이 오늘 할 일(휴가 승인·인사 변경 신청·결근 확정 등) 건수를 메뉴 배지로 보여 준다. ⑤ 시설 고장 같은 일은 본사에 업무지원 요청을 올린다. 근거: 예약 달력 ADR-RSV-06, 근태 정정 ADR-ATT-04, 처리 대기함 D61, 업무지원 D56.
