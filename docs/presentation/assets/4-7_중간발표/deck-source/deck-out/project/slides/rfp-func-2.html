RFP p.5 기능 1~8

조항

RFP가 요구한 것(원문 요약)

구현한 것

상태

근태관리

F3-1

현장별 > 개인별 근태 등록 관리

직원이 출퇴근을 찍고, 지점 관리자가 빠진 날을 등록·정정하며, 본사는 지점별 현황을 본다.

완료

F3-2

휴무·연차·병가 등 기록 및 일수 관리

연차·병가·휴무를 신청·승인하고, 남은 연차와 올해 종류별 사용 일수를 보여 준다.

완료

F3-3

업무일지 작성 관리

직원이 하루 한 건 업무일지를 쓰고, 지점 관리자가 직원 화면에서 읽는다.

완료

게시판

F4-1

본사→현장 / 현장→이용자 게시판 별도 생성

본사→현장 게시판과 현장→이용자 게시판을 나눴고, 회원에게는 현장 공지만 보인다.

완료

F4-2

본사→현장 직원관리 탭에 교육 매뉴얼·자료 탑재

'직원 교육자료' 탭에 교육 문서를 첨부해 올리고 직원이 내려받는다.

완료

F4-3

현장→이용자 각 시설에 대한 공지 글·이미지 작성

지점 공지를 쓸 때 시설을 고르고 서식과 이미지를 넣으면, 회원 앱에 시설별로 보인다.

완료

조항별 화면·결정 기록은 함께 낸 RFP 이행 증빙(PDF)의 같은 조항 번호

기능 요구(권한·인사·근태·게시판·회원·예약결제·강사프로그램·혼잡도). 조정 2개: 모바일 결제는 실제 PG 대신 모의 결제(상태 전이·결제/취소 경합은 실물처럼, D5·D6·ADR-RSV-07), 혼잡도 "실시간 또는 30분 이내"는 계측 장비 없이 진행 중 강습 예약 인원 자동 + 현장 인원 직원 입력(ADR-FAC-05). 해당 없음 1개는 원문이 "결제내역 처리 방법 추후 논의"로 미확정인 조항.
