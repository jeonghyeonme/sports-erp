Ⅵ. 6주차 이후 · 마지막 정리

역할을 정리하고, 혼잡도를 예약과 잇고, 문서를 냈습니다

관리자 웹은 직원만

회원 계정은 로그인 단계에서 막고 회원 앱으로 안내

혼잡도 = 예약 + 현장

진행 중 강습의 예약 인원은 자동, 예약 없이 온 인원은 직원 입력

문서 산출물

사용자 매뉴얼 · 교육 자료(게시판 탑재) · 진행 보고서 5부, 전부 10/23 기준으로 재생성

이 중간보고 묶음

이 보고서 · RFP 이행 증빙 · 주차별 발표자료 · 산출물

관리자 웹은 직원 계정만(D66): 회원 계정으로 로그인하면 발급된 토큰을 바로 폐기하고 회원 앱으로 안내한다. 관리자 웹의 회원용 화면 코드도 지웠다. 혼잡도(ADR-FAC-05): 혼잡도 = 지금 진행 중인 강습 회차의 예약 인원(조회 때 계산) + 예약 외 현장 인원(직원 입력). 입장 기록(키오스크) 방식은 설계했지만 RFP 요구를 넘어 보류. 문서 산출물: 사용자 매뉴얼(Word, 역할별), 교육 자료 빠른 시작(PDF, 운영 게시판 직원 교육자료 탭에 탑재), 단계별 진행 보고서 5부, 그리고 모든 산출물을 10/23 사실로 다시 생성. 이 중간보고 묶음: 이 덱 + RFP 이행 증빙 + 주차별 발표자료 + 산출물(D67).
