Ⅳ. RFP 이행 · 기능 (1/4)

기능 22조항 — 완료 19 · 조정 2 · 해당 없음 1

RFP p.5 기능 1~8

조항

RFP가 요구한 것(원문 요약)

구현한 것

상태

권한관리

F1-1

권한관리 기능은 관리자 계정에만 부여

직원의 역할을 바꾸고 권한을 정하는 화면은 본사 관리자만 연다.

완료

F1-2

사용자별·프로그램별 권한 설정(입력·수정·삭제·조회·출력)

기능마다 조회·입력·수정·삭제·출력을 켜고 끌 수 있고, 역할별 기본값에 사람마다 예외를 줄 수 있다.

완료

F1-3

본사-현장, 현장-이용자 간 별도 권한 관리

본사·지점 관리자·직원·회원 네 역할로 나누고, 지점 관리자는 자기 지점 데이터만 본다.

완료

F1-4

사용자 편의성·확장성·운영성 고려

지점 범위 검사를 한 곳에 모아, 새 화면을 만들어도 검사가 빠지지 않는다. 빠지면 자동 테스트가 실패한다.

완료

F1-5

퇴사 처리 이후 시스템 접근 통제

퇴사 처리하면 그 계정은 다음 요청부터 바로 막힌다.

완료

인사정보관리

F2-1

현장(지점)별 인사관리 탭, 코드 생성

직원 목록을 지점별로 묶어 보이고, 채용하면 직원 코드가 자동으로 붙는다.

완료

F2-2

모든 인사기록 정보를 한 화면에서 조회

직원 한 명의 파견·근태·휴가·업무일지·인사서류를 한 화면에서 본다.

완료

F2-3

권한부여 혹은 승인 시 수정 가능

직원이 자기 인사정보 변경을 신청하고, 지점 관리자가 승인해야 바뀐다.

완료

조항별 화면·결정 기록은 함께 낸 RFP 이행 증빙(PDF)의 같은 조항 번호

기능 요구(권한·인사·근태·게시판·회원·예약결제·강사프로그램·혼잡도). 조정 2개: 모바일 결제는 실제 PG 대신 모의 결제(상태 전이·결제/취소 경합은 실물처럼, D5·D6·ADR-RSV-07), 혼잡도 "실시간 또는 30분 이내"는 계측 장비 없이 진행 중 강습 예약 인원 자동 + 현장 인원 직원 입력(ADR-FAC-05). 해당 없음 1개는 원문이 "결제내역 처리 방법 추후 논의"로 미확정인 조항.
