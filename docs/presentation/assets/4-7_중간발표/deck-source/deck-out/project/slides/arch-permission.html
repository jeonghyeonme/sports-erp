지점 관리자 역할의 기본 권한 표

RFP F1-2 "사용자별·프로그램별 권한 설정(입력·수정·삭제·조회·출력)". 처음에는 역할 4개로 고정했다가(D1), RFP 문구를 다시 대조해 세부 권한을 만들었다(D60이 D1을 대체). 역할이 상한이고 그 안에서 기능 15개 × 동작 5개를 역할 기본값으로 두며, 본사가 사람마다 예외를 줄 수 있다. 개인 예외도 역할 상한을 넘지 못한다. 판정은 서버의 전역 권한 가드가 하고(선언이 빠진 경로가 있으면 자동 테스트 실패), 관리자 웹은 같은 판정으로 메뉴·버튼·CSV 내려받기를 숨긴다 — 숨김은 편의이고 막는 것은 서버다. 권한 변경은 변경 이력에 남는다.
