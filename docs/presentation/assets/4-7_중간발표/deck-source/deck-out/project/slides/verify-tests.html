화면 자동 테스트 밖의 화면은 시연 데이터로 직접 점검까지 했습니다

API 자동 테스트는 52개 파일 556건이고 실제 PostgreSQL 위에서 돈다(테스트마다 기준 DB를 복제). 지점 격리는 다른 지점 id로 공격하는 케이스 표를 모든 지점 단위 경로에 대해 돌리고, 리소스 선언이 빠진 경로가 있으면 실패한다. 계약 종료 차단, 인사 권한 분리, 동시성(정원 2명 회차에 동시 요청 → 정확히 2건, 결제와 취소 동시 처리, 겹치는 휴가)을 본다. 화면 자동 테스트(Playwright) 14건은 역할별 핵심 경로(본사 대시보드·지점 상세, 회원 등록, 회차 등록, 공지·첨부, 근태, 세부 권한, 처리 대기함, 첫 로그인 변경, 회원 계정 거부, 혼잡도, 회원 예약·결제·취소 등)를 빌드 결과로 본다. 그 밖의 화면은 lint·빌드와 시연 데이터 점검까지만. PR마다 CI가 모두 돌고, 커밋 전에도 같은 검사가 돈다.
