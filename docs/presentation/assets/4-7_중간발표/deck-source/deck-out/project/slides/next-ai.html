계약서 OCR·AI 분석(차별화전략 §1-1). 흐름: 계약서 스캔본을 올리면 글자를 인식하고 계약 상대방·기간 등을 뽑아 관리자에게 제안하고, 관리자가 확인한 뒤 반영한다. 자동 반영하지 않는 이유: 계약 상태는 신규 활동 차단(종료)·갱신 판단의 근거라 잘못 읽은 값이 그대로 퍼진다. 검토할 점: 인식률(스캔 품질·표 형식), 로컬 모델과 외부 API의 비용·정확도, 계약서에 든 개인정보를 외부로 보내도 되는지(위탁 문제). 지점 상세의 계약 정보 칸은 이를 전제로 이미 있다(D22). 계획 수준이고 RFP 조항이 아니다.
