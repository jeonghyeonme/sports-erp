지금 회원 기능은 휴대폰 웹(PWA, D40·D41·D45) — 같은 기술·같은 주소로 인프라를 더 붙이지 않으려는 결정이었다. 문제: 홈 화면 설치 방법이 브라우저마다 다르고, 카카오톡 같은 인앱 브라우저에서는 설치·로그인 유지가 제한되며, 푸시 알림도 기기마다 다르다. 대안: 웹을 감싼 하이브리드 앱(코드 재사용이 크고 스토어 배포 가능) / 네이티브 앱(접근성·기능은 가장 좋지만 코드를 새로 짜야 함). 비교 기준: 접근성 · 코드 재사용 · 스토어 배포 · 비용. D40을 다시 판단하는 일이고 계획 수준이다.
