한 장 요약. 무엇을: 아파트·오피스텔 커뮤니티 시설을 위탁받아 운영하는 회사(스포이즘)의 본사·지점·회원 시스템. 누구를 위해: 본사 관리자, 지점 관리자, 직원(관리자 웹), 회원(휴대폰 웹). RFP: 원문 글머리 하나를 한 조항으로 나눠 72조항 — 판정 원천은 요구사항추적표 §3이고 조항별 증거는 RFP 이행 증빙(PDF). 확인: 실DB 위 API 자동 테스트, 역할별 화면 자동 테스트, 운영 환경 성능 측정, 시연 데이터로 화면 점검. 다음: 실운영은 하지 않는다 — 기능을 늘리기보다 사용감을 다듬고, 계약서 OCR·AI 분석 적용을 검토하고, 회원 앱 형태를 다시 판단한다.
