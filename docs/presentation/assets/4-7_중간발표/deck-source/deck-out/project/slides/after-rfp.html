"MAP 형태의 페이지 위치"처럼 모호한 문구는 해석을 결정 기록으로 남기고 구현했습니다

6주차 이후 RFP 원문을 문구 단위로 다시 대조해(D51 — "페이지 위치" = 경로 표시 등 해석 결정), 빠졌거나 화면이 없던 것을 채웠다. 인사: 직원 상세 한 화면(인사기록), 본인 인사 변경 신청 → 지점 관리자 승인(ADR-STF-09). 근태: 관리자 정정·누락일 등록(ADR-ATT-04), 본사 근태 현황, 업무일지 관리자 열람. 회원 서비스: 프로그램 종목·연령대·시간대 필터(ADR-PRG-04), 회원 웹 강사 소개, 예약 달력(관리자 주간 시간표·회원 날짜 띠, ADR-RSV-06), 혼잡도 30분 경고. 공통: 목록 CSV 출력(D54), 변경 이력 확대(D52), 느린 요청 안내(D55), 경로 표시, 회원 웹 이용 안내·개인정보처리방침. 소통: 직원 교육자료 탭·첨부(D57), 업무지원 요청(D56).
