개발 작업계획서(5-2), 정식 명칭은 "개발 작업계획서 겸 프로젝트 구조 개요". 왼쪽은 문서의 실제 화면으로, 관리자·회원이 admin-web과 member-app을 거쳐 하나의 REST API(NestJS)를 쓰고, 그 뒤가 데이터 저장소라는 구조가 그려져 있다. 데이터 저장소는 설계 목표가 PostgreSQL(Prisma)이고 현재는 인메모리 mock으로 동작한다. 계획서의 원칙은 날짜로 쪼개기보다 "이 범위가 끝나면 이런 데모가 나온다"는 완성 단계를 정의하는 것이다.
