PT 패키지 등록 10→6은 기본값 채우기(구매일 = 오늘, 10→9)와 빠른 찾기를 합친 값이고, 측정 회원은 PT가 있어 PT 탭이 먼저 열린다(PT가 없는 회원이면 7). 글자마다 호출이 늘지 않게 2자·0.3초 조건(무료 한도, D40).
