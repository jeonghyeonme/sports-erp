역할 4개(D1·D12). 채용·재배치는 본사 관리자만(인사 권한 분리 불변식). 주의: 채용·재배치·퇴사 처리는 API로 구현됐지만 직원 화면은 조회 전용이라 "API로 구현, 화면은 후속 과제"라고 말할 것. 회원 기능은 회원 앱이 아니라 회원 계정으로 로그인한 관리자 웹 화면에서 쓴다.
