지방 15곳을 빼면 하루 약 9.3만 건 → 한도 안에서 회원 모바일 웹 진행

계산값 — 지점당 하루 100명 · 방문당 10건 가정, 관리자 웹 약 1만 건 포함

파트 1 범위 슬라이드에서 이미 설명한 결정을 시간순 위치에서 짚는다. Lambda로 처리 성능 문제는 풀었지만 요청 개수 한도(무료 티어)는 별개 문제다. 지점당 하루 100명 × 방문당 10건 가정으로 98곳 전부 열면 하루 약 10.8만 건(관리자 웹 포함)으로 Workers 무료 한도 10만 건을 넘는다. 수도권 83곳이면 약 9.3만 건. 그래서 대상을 수도권으로 줄이고, 회원 기능은 관리자 웹과 같은 스택의 모바일 웹으로 만든다(인프라 추가 없음). 사용자가 늘어 한도를 넘게 되면 Workers 유료(월 $5) 전환과 함께 지방 현장을 연다.
