왜 네 겹인가

③은 경로에 지점 ID가 있을 때만 봅니다. 단건 조회는 경로에 지점이 없어서 ④가 직접 확인합니다.

검증

다른 지점 ID로 공격하는 케이스 표를 자동 테스트가 매번 돌립니다.

검증: apps/api/test/branch-isolation.spec.ts

지점 격리는 두 겹이다. ③ 공통 가드는 경로·쿼리에 지점 ID가 있으면 내 지점인지 본다. 하지만 /members/:id 같은 단건 라우트는 지점 ID가 경로에 없으므로 ④ 컨트롤러가 꺼낸 데이터의 지점을 직접 확인한다. 존재 자체를 숨겨야 할 때는 404. 지점 단위 라우트를 추가하면 격리 테스트(branch-isolation.spec)의 공격 케이스 표에도 함께 추가하는 것이 규칙이다. 공통 가드로 중앙화하는 안은 사용자 승인 대기.
