회원 기능은 모바일 웹으로 — 관리자 웹과 같은 스택·같은 엣지라 인프라를 더 붙이지 않습니다.

요청 수는 계산값(지점당 하루 100명 · 방문당 10건 가정) · 무료 한도: Cloudflare Workers 10만/일 · 처리 한계는 10/4 k6 실측

대상 지점을 정한 계산. 전부 계산값이다: 지점당 하루 회원 모바일 웹 사용자 100명(가정 — 아파트 커뮤니티 시설 규모로 잡은 값) × 방문 1회당 API 요청 10건(가정 — 관리자 웹 화면 한 번에 조회 2~4건을 참고) + 관리자 웹 하루 약 1만 건. 98개 전체면 약 10.8만 건으로 Cloudflare Workers 무료 한도(하루 10만 건)를 넘고, 넘는 날은 그날 남은 요청이 전부 실패한다. 수도권 83곳이면 약 9.3만 건으로 한도 안. 여유는 7% 정도라 사용자가 더 늘면 Workers 유료(월 $5)로 넘어간다 — 그 시점에 지방 현장도 다시 연다. Lambda는 월 약 280만 건으로 무료 100만 건을 넘지만 요청 요금이 월 1달러 미만이라 판단에 영향 없음. 처리량은 피크 시간대 약 3 rps, 순간 몰림을 크게 잡아도 약 8 rps로 10/4 k6 실측 한계(약 50 rps) 안. 동시 실행 상한 10은 관리자·회원 요청이 함께 쓰고, 몰림 때 필요한 칸은 약 1칸. 요청 수·피크는 "계산값", 처리 한계는 "실측"으로 구분해서 말할 것.
