RFP Ⅳ 2. 세부 과업 내용 표의 기능 요구 8개(원문 번호 1~8)와 성능 요구 2개(10·11, 원문에 9번은 결번). 자원문서관리는 기능 표가 아니라 과업1 "인적/물적자원 관리 현황"에서 나온 9번째 도메인 — 원문 번호가 없어 맨 아래 + 행으로 따로 두었다. 성능 요구는 처음엔 설계 원칙으로 대체했다가(D14) 실제 배포 후 k6로 실측하는 쪽으로 다시 열었다(D24).
