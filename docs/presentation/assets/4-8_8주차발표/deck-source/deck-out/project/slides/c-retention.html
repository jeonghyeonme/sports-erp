보존 끝난 파일 정리

이관 완료 + 보존 기간 지남일 때만

누가 지웠는지 기록, 실패하면 전부 되돌림

보존 기간(D69·D71, 사용자가 정한 값): 회차가 끝난 날(해지로 끝나면 해지 확정일, 아니면 종료일)부터 시스템 3년, 이후 실물 7년. 보존 끝은 저장하지 않고 회차에서 계산한다 — 종료일을 정정하면 따라간다. 실물 이관 완료는 본사가 파일마다, 언제든(보존 끝 전에도) 표시한다. 표시해도 보존 기간 동안은 시스템에서 열람된다. 시스템 파일은 "이관 완료 + 보존 기간 지남"일 때만 본사가 정리 버튼으로 지운다. 보존 끝 6개월 전부터 이관 안 한 파일을 처리 대기함에 띄운다. 이유: 보존 기간 안에는 시스템에서 열 수 있어야 하고, 지우는 일은 사람이 확인한 뒤 누가 지웠는지 남겨야 한다. 정리 중 저장소 삭제가 실패하면 기록까지 전부 되돌린다. 정리된 파일 기록(행)은 남는다. 화면은 로컬 미리보기로만 확인했다.
