새로 만든 계약 상태 변경은 처음부터 API와 화면을 함께 만들었습니다

지난 발표에서 "API로 구현, 화면은 후속 과제"라고 했던 기능 5개. 인사 채용·파견·퇴사는 직원 상세 화면에서(PR #38). 비밀번호 변경은 관리자·회원 모두, 바꾸면 모든 세션 종료(ADR-AUTH-05), 데모 계정은 잠금. 회원 가입·연동은 회원 웹에서(PR #40). 결근 확정은 배치가 아니라 관리자가 미리보기 보고 확정(ADR-ATT-02, PR #44). 자산 수정은 취득 정보(취득일·금액)를 회계 기록이라 잠그고 이름·위치·메모만(PR #44). 계약 상태 변경은 새로 만든 API에 화면까지 같이(PR #51). 화면은 lint·빌드와 수동 확인까지 — 자동 테스트 없음.
