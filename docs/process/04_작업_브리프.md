# 04. 작업 브리프 — 남은 일을 세션 하나씩으로 나눈 계획 (2026-10-07, B2 2026-10-14)

> [문서 지도](../README.md) · 우선순위와 진행 상태는 [STATUS](../STATUS.md)가 기준이다. 이 문서는 "그 일을 새 세션에서 어떻게 시작하나"만 담는다.
> 끝난 브리프는 지우고 경위는 `log/`로 보낸다(STATUS와 같은 방식).

## 공통 — 모든 세션

1. **시작**: `CLAUDE.md`(자동) → [STATUS](../STATUS.md) → 이 문서의 해당 브리프 → 관련 도메인 요약 카드.
2. **브랜치**: `dev`에서 새 작업 브랜치를 딴다(D39). 끝나면 `dev` 대상 PR → CI 통과 → rebase 병합. `main`에는 손대지 않는다.
3. **근거 먼저**: 구현 전에 근거 ID(ADR·D)를 밝힌다. 결정이 없으면 대안·트레이드오프를 먼저 적고 사용자에게 고르게 한다.
4. **로컬 테스트 DB**: PG16 클러스터. `pg_ctlcluster 16 main start` → `apps/api/.env`(gitignore, `.env.example` 참고) → `npx prisma migrate deploy --schema=apps/api/prisma/schema.prisma` → `npm run prisma:seed --workspace=apps/api`. 새 clone이면 `npm ci`와 `npm run prisma:generate`를 먼저 실행한다.
5. **커밋**: `git add`와 `git commit`을 따로 실행한다. 한 명령으로 묶으면 커밋 전 hook이 막는다. 메시지는 한국어로 쓰고 근거 ID를 넣는다.
6. **마무리**: `wrap-up` 스킬(STATUS + `log/NNN.md`).
7. **사용자 승인 대상**: 배포 DB(Supabase) 쓰기, 스키마 변경, 범위 제외 항목 구현. 배포 DB 쓰기는 Supabase 커넥터 인증이 필요하다. 2026-10-06에 인증 오류가 나서 사용자가 SQL Editor에서 직접 실행했다(log/074).

## B1. 회원 모바일 웹 — D40·D41 (남은 일만, 2026-10-08)

B1-1~B1-4 구현은 끝났다(log/077·083·084·085). 남은 것:

1. ~~사용자: Worker 배포~~ — 2026-10-09 사용자가 배포했다(log/092). 이후 화면 변경은 같은 명령(`npm run build:web` → `cd cloudflare-worker && npx wrangler deploy`)으로 다시 올린다. 휴대폰에서 `/m/` 로그인 → 예약 → 결제 → 취소, `/m/reservations` 새로고침을 확인한다.
2. **운영 실측** — 배포 후 며칠 동안 Cloudflare 대시보드의 Worker 일일 요청을 본다. 9만을 넘으면 D40 재고 트리거대로 Workers 유료를 검토하고 design-constants ⑩·⑬을 고친다(log/085).
3. ~~(선택) 회원 가입·연동 화면~~ — 2026-10-09 구현(`/join`·`/signup`·`/link`, ADR-MEM-05, log/092).
4. **(요청 시) 덱 `req-shot-member` 캡처 갱신** — 보호 영역(`docs/presentation/`).

**주의**: 회원 웹은 자동 테스트가 없다(CI는 lint·빌드). 화면 작업은 360px Playwright로 확인하고 "검증되지 않음(수동 확인)"으로 보고한다. 수동 확인용 api는 복사본 DB로 띄운다 — jest가 기준 DB를 템플릿으로 쓴다(log/083).

**권장 순서**: M1·M3(API 거의 그대로, 결정 작음) → M2·M7(근태 정정 + 그 기록) → M4 → M5·M6·M8 → M9·M10(승인·외부 결정 필요).

**완료 기준(항목마다)**: 요구사항추적표 §2-3 행을 지우거나 "구현"으로, 해당 도메인 부록 A-4/A-5·요약 카드, 지점 단위 라우트를 더하면 `branch-isolation` 공격 표·`@ScopedResource`, 관리자 화면이면 `help-content.ts`, 마무리는 wrap-up(log 새 번호).

**주의**:
- 로컬 Playwright로 화면을 확인할 때 쓰는 기준 DB가 jest 템플릿이다 — 확인 뒤 `prisma migrate reset --force --skip-seed` + 시드로 되돌리지 않으면 커밋 hook의 jest가 깨진다(log/112에서 겪음).
- 이 컨테이너는 재시작되면 PG16이 꺼져 있다 — `pg_ctlcluster 16 main start`.
- 개발 서버를 `pkill`로 끄면 셸이 같이 끊길 수 있다 — PID를 골라 `kill`.
