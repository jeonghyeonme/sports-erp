1-3 인사정보관리

인사정보관리: 본사가 채용하고 지점에 파견한다. 재배치도 본사만 할 수 있고 이전 파견은 기록으로 남는다. 지점 관리자는 현재 파견된 직원의 일상 관리(정보 수정, 퇴사 처리)만 한다. 이 구조는 기업 분석에서 발견한 것이다. 주의: 채용·재배치는 API와 통합 테스트로만 구현했고 admin-web에는 화면이 없다("화면에서 채용한다"고 말하지 말 것).
