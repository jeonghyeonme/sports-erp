2-3 요구사항 추적표 §2-4

이 발표의 핵심 슬라이드(1분 30초). 분석에서 발견한 공백이 설계 결정과 구현으로 이어졌다는 증거다. 제외·미구현 행은 슬라이드에 넣지 않았다. 문장: "분석서에는 실무 전체를 명시하되, 구현을 진행하면서 불필요하다고 판단한 것은 제외하는 방향으로 진행했다." 부가세 행은 백업이며 질문이 나오면 구성안 §5-6으로 답한다.
