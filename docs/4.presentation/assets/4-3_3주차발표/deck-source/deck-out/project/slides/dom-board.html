게시판: 본사 공지는 전체 또는 지정한 지점에, 지점 공지는 자기 지점의 회원·직원에게 간다. 지점 사용자는 전체 공지와 자기 지점의 글만 볼 수 있다. 시연: 본사·지점 공지 작성, 작성자 본인만 수정. [시연 스크린샷 자리]
