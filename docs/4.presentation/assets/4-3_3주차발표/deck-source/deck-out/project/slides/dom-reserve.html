예약·결제: 예약 흐름과 24시간 환불 기준(지점별 설정, 기본 24시간). 예약할 때 진행중·정원·중복을 확인한다. 동시성은 구두로: 문서는 DB 행 락을 설계했고, 지금은 동기 실행 mock이라 별도 락 없이 안전하며 DB 전환 시 락을 복원한다. 시연: 회원 예약 → 결제 대기 → 모의결제 → 확정 → 취소(자동 환불). 회원 앱이 미착수라 회원 화면은 회원 계정으로 로그인한 관리자 웹 화면이다.
