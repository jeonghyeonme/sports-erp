1-2 권한관리

권한관리: 4개 역할과 3관문. 요청은 로그인 → 역할 → 지점의 세 관문을 통과해야 데이터에 닿고, 다른 지점의 데이터는 마지막 관문에서 막힌다. 지점 격리는 가드와 컨트롤러가 이중으로 검사한다. 질문이 나오면(구성안 §5-5): 자동 테스트로 확인했고 그 과정에서 검사가 빠져 있던 라우트 1건을 찾아 수정했다. [사이드바 역할별 비교 캡처 자리 — 본사 vs 지점 관리자 vs 회원]
