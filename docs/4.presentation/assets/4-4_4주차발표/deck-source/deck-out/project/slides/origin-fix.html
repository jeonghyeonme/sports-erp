이후 — 오리진을 통합

admin-web을 같은 Worker의 정적 자산으로 흡수 — CORS라는 변수 자체가 사라짐

D25 · 2026-09-28 사용자 확인 — 로그인·새로고침 둘 다 해소

D24 배포 직후 로그인 실패·새로고침 404가 났다. 원인은 admin-web(Render)과 api 게이트웨이(Cloudflare Worker)가 서로 다른 주소(오리진)가 된 것. 각 버그를 따로 땜질하는 대신, admin-web을 아예 같은 Worker의 정적 자산으로 통합해 오리진 분리 자체를 없앴다(D25). 이 과정에서 실제로 겪은 두 개별 버그(_redirects 무한루프, .env 프로덕션 오염)는 Q&A로만 다룬다.
