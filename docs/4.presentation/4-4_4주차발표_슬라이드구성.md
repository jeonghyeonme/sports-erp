## 0. 발표 조건

- 형식: 슬라이드 + 실제 화면 캡처 (라이브 데모 여부는 §5-1 확인 후 결정)
- 분량: 15분 내외, 16장 안팎
- 청중: 개발 지식이 있는 분들(3주차와 동일). 클래스명·오류 코드·영문 상태값은 슬라이드에 쓰지 않는다
- **이번 주만의 전제**: 3주차가 "9개 도메인을 다 만들었다"였다면 이번 주는 **새 기능보다 "근거를 붙여 다시 뜯어보고, 인터넷에 올려 실제로 재 봤다"** 가 중심이다. 기능 나열이 아니라 "방법 → 그 방법이 찾아낸 것 → 배포·실측이 찾아낸 것" 흐름으로 보여준다
- 회원 앱은 여전히 미착수 — 회원 연동·가입은 **API와 테스트만** 있다(화면 없음)

## 1. 서사

**"만든 것을 근거로 다시 검증했더니 결함이 나왔고, 실제로 배포해 재 보니 설계가 바뀌었다."**

1. 방법론: RFP 문장 → 요구사항 분류 → Architecture Driver → 대안 비교 → ADR → 테스트, 이 사이클을 9개 도메인 전부에 돌렸다 (ADR 26개)
2. 그 사이클이 실제 결함을 찾았다: 시간대 버그 10곳, 회원에게 직원용 공지 노출, 계약 종료 지점 차단 누락 3개 도메인 등 → 고치고 테스트로 고정 (119 → 251건)
3. 배포하고 부하를 걸어 보니 "로그인 40명 동시에 p95 15초" — 계산(Little's Law)으로 원인 구조를 설명하고 3단계 로드맵(D24)을 세워 1단계(엣지 rate limit)까지 배포했다

## 5. 발표 전 확인할 것 (Q&A 대비 포함)

1. **배포본 로그인이 실제로 되는지 아직 확인되지 않았다.** 마지막 기록(진행 로그 §36)은 "`.env`가 프로덕션 빌드에 섞이던 원인을 고쳤고, 재배포 후 브라우저 확인 필요"에서 멈춰 있다. rate limit(11번째 요청부터 429)도 미확인이다. 확인 전에는 "배포해서 동작한다"가 아니라 "배포했고, 로그인 확인 중"으로 말한다. 확인되면 슬라이드 13에 실제 화면을 넣는다.
2. **테스트 범위가 넓어졌다 — 그래도 전체는 아니다.** 3주차엔 3개 영역(지점 격리·계약 종료·인사 권한)뿐이었지만 이번 주에 예약 정원·중복, 근태 결근·귀속, 프로그램 무결성, 시설 생명주기, 게시판 공개 범위, 문서 보존기한, 회원 연동·가입·상세가 추가됐다. **admin-web 화면은 여전히 자동 테스트가 없다**(회원 상세 탭만 브라우저로 한 번 눈으로 확인). "전부 테스트됐다"고 말하지 말 것.
3. **실DB는 아직 아니다.** Supabase에 스키마를 올리고 RLS를 켰지만 API는 여전히 인메모리 mock이다. 스키마가 mock보다 뒤처져 있다(자산·문서 모델 없음, 수강 상태 값 불일치).
4. **"행 락" 계열 ADR(예약 정원, 인사 채번, 파견 유일성)은 실DB 전환 때 구현되는 설계다.** 지금은 동기 실행 mock이라 테스트로 동작을 확인한 것이고, DB 수준 락이 있는 게 아니다.
5. **부하테스트 수치의 성격.** 사용자가 로컬에서 k6를 돌린 결과 1회이고, Render 무료 티어 대상이다. "우리 코드가 느리다"가 아니라 "무료 인프라에서 CPU 바운드 로그인이 병목"이라는 해석이다. 로그인 도착률 계산은 "로그인 1회 = 시설 도착 1회" 가정에 기대고 있다(design-constants.md의 약한 고리).
6. **판단 오류도 기록했다.** D24의 "Cloudflare는 도메인이 필요하다"는 판단이 틀려 정정했고, D25 배포 때 `.env`가 프로덕션에도 로드된다는 걸 놓쳐 로그인 실패를 한 번 더 겪었다. 질문이 나오면 숨기지 말고 "진행 로그에 틀린 판단과 정정 과정까지 남겼다"로 답한다.
7. **관리자 웹 배포가 수동이 됐다.** Worker 통합(D25)으로 git push 자동 배포 대신 로컬 빌드 후 `wrangler deploy`가 필요하다. Worker가 UI·API 관문을 모두 맡는 단일 실패 지점이 된 것도 감수한 트레이드오프다.
8. **인사 채용·재배치 화면은 여전히 없다**(3주차와 동일, API만).
9. **죽은 코드 정리.** 폐기된 실DB 실험 브랜치에서 온, 한 번도 등록된 적 없는 응답 인터셉터 등 3개 파일을 삭제했다(테스트 결과 전후 동일). 슬라이드에는 넣지 않는다.
